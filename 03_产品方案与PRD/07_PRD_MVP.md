- 里程碑版本：`v2026.08.07.2`
- 当前状态：需求基线
- 对应原型：`../04_可视化原型/index.html`

## 结论

巴布 MVP v0.8 是面向一人公司、品牌主和个人 IP 的小红书内容工作台。当前用三个一级模块承接内容任务，并用个人中心承接低频账户操作：

- 对话：帮助用户梳理定位、选题、草稿和表达问题；
- 创作：基于账号资料、内容主线或商品主线批量生成笔记，并为单篇笔记生成配图；
- 账号：管理不同小红书账号及其品牌、个人 IP、商品和服务资料。
- 个人中心：查看注册信息、修改密码和退出登录，并为充值与消费记录预留入口。

当前里程碑确认的是产品需求、界面结构和可交互静态原型，不代表真实 AI、数据库、图片生成服务或小红书平台能力已经接入。

## 产品目标

让用户不必从空白写作开始，可以先沉淀账号资料，再通过对话或创作工作流得到可直接使用的小红书笔记和配图。

本版优先验证：

1. 三列结构是否能让用户快速理解当前模块和上下文；
2. 对话是否能降低定位、选题和改写的启动成本；
3. 内容/商品主线是否能让创作结果更贴合账号；
4. 只读笔记结果和单篇配图是否足以支持发布前准备；
5. 用户是否会按账号回看创作历史并继续使用；
6. 个人中心是否能让用户清楚地区分当前可用账户操作和后续预留能力。

## 目标用户

### 品牌账号

- 有自己的品牌、商品、门店或服务；
- 希望把产品卖点转成真实使用场景；
- 需要稳定的内容方向和批量笔记；
- 不以销售额或转化率作为 MVP 承诺。

### 个人 IP

- 有专业能力、经历、观点或服务；
- 希望形成稳定定位和持续表达；
- 需要把真实经历和专业判断转成小红书内容；
- 不以涨粉、爆款或平台推荐作为 MVP 承诺。

## 信息架构

### 未登录

- 首页：产品定位、核心能力和进入工作台入口；
- 登录弹窗：账号、密码和登录操作。

### 登录后三列工作台

| 区域 | 作用 | 内容 |
| --- | --- | --- |
| 左侧一级菜单 | 切换产品模块 | 对话、创作、账号、积分、个人中心 |
| 中间上下文栏 | 管理当前模块的对象 | 对话列表或账号列表，以及新建入口 |
| 右侧工作区 | 完成当前任务 | 对话聊天、创作流程、账号资料或历史详情 |

个人中心是布局例外：保留左侧一级菜单，隐藏中间上下文栏，使用整块右侧区域展示账户信息与安全操作。

## 核心用户路径

### 路径 A：对话

**登录 -> 对话 -> 新建或选择历史对话 -> 输入问题 -> 等待回复 -> 继续追问。**

### 路径 B：创作

**登录 -> 创作 -> 选择账号 -> 选择内容主线或商品主线 -> 选择具体主线/商品 -> 设置正文字数和生成篇数 -> 生成笔记 -> 查看笔记详情 -> 选择 1-6 张生成配图。**

### 路径 C：创作历史

**创作 -> 创作历史 -> 查看当前账号全部历史笔记 -> 点击笔记 -> 查看只读详情 -> 按需生成配图 -> 返回历史列表。**

### 路径 D：账号

**账号 -> 新建账号 -> 选择品牌或个人 IP -> 填写账号资料 -> 填写品牌/个人 IP 资料 -> 品牌账号继续填写商品 -> 保存 -> 查看账号资料。**

### 路径 E：个人中心

**个人中心 -> 查看注册邮箱，或填写当前密码和新密码完成修改，或点击退出登录 -> 二次确认 -> 返回未登录首页。**

## 功能需求

### 1. 登录与个人中心

P0 必做：

- 账号密码登录；
- 登录失败提示；
- 会话保持；
- 个人中心展示当前登录邮箱；
- 修改密码包含当前密码、新密码和确认新密码，新密码至少 6 位且两次输入一致；
- 退出登录需要“是 / 否”二次确认，取消后停留当前页，确认后回到未登录首页；
- 充值和消费记录显示“即将开放”，当前不可操作；
- 登录后根据账号数据进入对应工作区。

当前不做注册、找回密码、验证码、微信登录、小红书授权、真实充值、账单查询、套餐和支付。

### 2. 对话

#### 2.1 对话列表

- 中栏固定提供“新建对话”；
- 支持按标题和摘要搜索历史对话；
- 历史对话按时间分组；
- 当前对话有清晰选中态；
- 每项展示标题、摘要和最近更新时间；
- 不显示重复的“历史对话”栏目标题；
- 所有会话项保持一致高度；
- 新建对话后自动进入空白对话。

#### 2.2 对话工作区

- 顶部居中展示当前对话标题，不重复显示更新时间；
- 空白对话展示快捷问题；
- 输入区支持最多 2000 字；
- 点击发送或按 Enter 发送；
- 输入框获得焦点时不增加额外边框或改变组件尺寸；
- 空输入不可发送；
- 发送后立即显示用户消息和等待状态；
- 回复完成后展示助手消息；
- 新消息更新对话标题、摘要和时间；
- 对话内容保留在当前原型会话中。

#### 2.3 对话边界

- 对话是独立一级模块，不是创作页里的生成模式；
- 对话可用于定位、选题、草稿改写和表达检查；
- 当前原型回复为固定逻辑，不代表真实 AI 质量；
- 对话不会自动创建创作任务或发布内容。

### 3. 账号

#### 3.1 账号列表

- 支持多个账号展示、搜索和切换；
- 每项展示头像、昵称、账号类型、小红书号和内容数量；
- 当前账号有清晰选中态；
- 提供新建账号入口。

#### 3.2 创建账号

- 先选择品牌或个人 IP；
- 品牌路径为“账号 -> 品牌 -> 商品”；
- 个人 IP 路径为“账号 -> IP”；
- 支持上一步、下一步和最终保存；
- 切换账号类型时同步调整步骤和字段。

账号基础字段：头像、昵称、小红书号、账号简介。

品牌资料字段：品牌名、细分方向、定位、目标用户、用户问题、品牌标签。

商品字段：商品首图、商品名、定价、卖点、消费场景和使用场景。品牌账号可保存多组商品，每组保留 1-3 张商品图。

个人 IP 字段：IP 方向、身份标签、专业能力、真实经历、核心观点、产品或服务和人设边界。

#### 3.3 账号详情

- 右侧区域展示当前账号摘要和公开数据；
- 品牌账号提供“账号资料 / 商品”视图；
- 个人 IP 提供“账号资料 / 产品或服务”视图；
- 商品可横向选择，详情随选中商品切换；
- 账号页仅在用户明确进入编辑流程后可修改资料。

### 4. 创作

#### 4.1 账号选择

- 中栏展示可用于创作的全部账号；
- 支持搜索和切换；
- 切换账号后，右侧内容主线、商品主线、笔记预览和创作历史同步切换；
- 当前账号资料不完整时应提示补充。

#### 4.2 创作主线

支持两种主线：

| 主线 | 数据来源 | 选择方式 |
| --- | --- | --- |
| 内容主线 | 账号定位、品牌或个人 IP 资料 | 从系统推荐的多个方向中单选 |
| 商品主线 | 当前品牌账号的商品资料 | 通过商品首图和标题单选商品 |

规则：

- 默认进入内容主线；
- 同一时间只能选择一种主线和一个候选项；
- 商品主线必须显示商品第一张图和商品标题；
- 个人 IP 无商品时不显示无效商品选项。

#### 4.3 生成设置

生成设置横向排列两个参数组和一个主操作：

| 参数 | 规则 |
| --- | --- |
| 正文字数 | 精简正文 200-400 字、标准正文 500-700 字、长图文正文 800-1000 字，三选一 |
| 生成笔记数 | 1-5 篇，步进增减，默认 3 篇 |
| 操作 | 生成笔记 |

规则：

- 页面只保留一组生成设置；
- 设置与主线使用右侧可用宽度，不集中挤在左侧；
- 长文字允许换行，但不得撑高或挤压相邻控制；
- 点击生成后按选择数量更新笔记预览。

#### 4.4 笔记预览

- 按序号展示生成的 1-5 篇笔记；
- 每篇展示标题、正文摘要和话题；
- 不展示草稿、已保存、待编辑等状态；
- 整行点击进入笔记详情；
- 生成结果直接提供给用户查看和使用。

#### 4.5 笔记详情

- 展示标题、完整正文和话题；
- 标题、正文和话题均为只读；
- 不提供编辑、保存或发布按钮；
- 顶部只保留“返回”；
- 详情内容与图片区域使用足够宽度，减少无意义留白。

#### 4.6 生成配图

- 位于单篇笔记详情中；
- 用户可选择 1-6 张；
- 点击“生成配图”后展示加载状态；
- 数秒后展示所选数量的图片；
- 再次生成时替换当前结果；
- 宽屏单行最多展示 3 张图；
- 图片数量不足 3 张时不拉伸图片填满整行；
- 当前只保留“生成配图”，不提供“内容变成图片”。

### 5. 创作历史

- 页面标题统一为“创作历史”；
- 按中栏当前选中账号过滤；
- 展示该账号的全部历史笔记，而不是生成任务汇总表；
- 每行展示封面、标题、正文摘要、话题、时间和“查看详情”；
- 点击后进入只读笔记详情；
- 详情中可继续生成 1-6 张配图；
- 历史页不提供“新建创作任务”按钮；
- 无历史笔记时展示明确空状态。

## 结果与内容规则

- 标题默认不超过 20 个字；
- 正文不超过 1000 字，并符合所选字数档位；
- 每篇包含 3-8 个相关话题；
- 不直接复制对标内容；
- 不伪造真实经历、效果、销量或用户反馈；
- 品牌内容不承诺销售、功效或绝对结果；
- 个人 IP 内容不承诺涨粉、爆款或平台推荐；
- 商品图片优先使用用户提供素材，不凭空伪造真实商品。

## 原型状态

当前静态原型需覆盖：

- 登录成功与退出；
- 个人中心、修改密码校验、退出确认和取消；
- 对话空白、新建、历史、搜索、发送、等待和回复；
- 账号空状态、多账号、品牌创建、个人 IP 创建和详情；
- 创作主线切换、商品首图、生成设置、1-5 篇笔记预览；
- 创作历史、只读详情、1-6 张图片加载和结果。

## P0 不做

- 真实小红书授权、自动登录和自动发布；
- 自动评论、私信或获客；
- 大规模平台抓取、账号库和持续监控；
- 数据看板、发布反馈和自动复盘；
- 团队权限、CRM、支付和完整会员体系；
- 真实充值、余额和消费账单；
- 手机端专门适配；
- 视频生成和复杂图片编辑器；
- 内容变成图片；
- 在生成结果里编辑、保存状态或发布。

## 验收标准

### 对话

- 用户能新建、搜索和切换历史对话；
- 用户能通过按钮或 Enter 发送消息；
- 发送后有等待反馈并显示回复；
- 对话列表与当前会话内容同步更新。
- 顶部标题居中且不显示重复时间，会话项高度一致，输入聚焦不产生额外边框。

### 个人中心

- 左侧入口显示“个人中心”，进入后使用左侧菜单和整块右侧区域；
- 注册信息展示当前登录邮箱，充值和消费记录入口为禁用状态；
- 修改密码能校验必填、最少 6 位和两次输入一致；
- 退出登录必须先二次确认，选择“否”关闭弹窗，选择“是”回到未登录首页。

### 账号

- 用户能创建品牌或个人 IP 账号；
- 品牌和个人 IP 步骤、字段、详情正确区分；
- 品牌账号能保存并切换多个商品；
- 多账号搜索、切换和右侧详情联动正确。

### 创作

- 用户能选择内容主线或商品主线；
- 商品选项同时展示第一张图和标题；
- 字数和篇数设置横向排列且无重复；
- 用户能生成 1-5 篇笔记并打开只读详情；
- 详情不出现编辑、状态和保存按钮；
- 用户能选择 1-6 张配图，看到加载状态和对应数量结果；
- 宽屏每行最多展示 3 张图片。

### 创作历史

- 标题显示“创作历史”；
- 页面按当前账号展示全部历史笔记；
- 列表项可进入只读详情并返回；
- 页面不存在新建任务按钮和任务汇总表。

### 布局

- 对话、创作、账号均保持三列关系，个人中心按账户任务使用两区布局；
- 账号页、创作页和创作历史的右侧区域使用一致的内容宽度与间距；
- 当前支持的桌面视口无横向溢出、文字遮挡或无意义滚动条。

## 指标与验证

原型阶段不统计业务增长指标，先通过走查记录以下信号：

1. 用户能否独立完成一次对话；
2. 用户能否理解内容主线和商品主线；
3. 用户能否在 2 分钟内生成并打开一篇笔记；
4. 用户是否认为至少一篇笔记可直接使用；
5. 用户是否会进入创作历史或生成配图。

## 风险与边界

- 对话和创作职责可能被混淆：保持一级入口独立，并分别验证使用场景；
- 只读结果可能限制细改需求：先验证直接可用比例，再决定是否恢复轻编辑；
- 图片生成成本可能失控：真实产品需限制次数、尺寸和并发；
- 商品图片可能失真：真实产品优先使用上传素材，生成内容必须标明边界；
- 小红书平台能力不稳定：账号资料以手动录入为可靠路径。
- 个人中心可能被误解为已接入真实账户和支付：原型阶段明确标注边界，工程化前单独验收认证与账务安全。

## 下一步

1. 用本里程碑原型完成少量真实用户走查；
2. 记录对话、创作、历史和配图四段任务的完成率与阻塞点；
3. 根据结果决定是否进入真实前后端和 AI 接入；
4. 正式开发前再拆工程任务和生产验收标准。
