# 小红书定位与内容验证助手 - MVP v0.1 PRD

更新日期：2026-06-11

当前状态：PRD 草案。

说明：本文用于固化当前 MVP 产品方案。当前只到产品需求文档，不进入产品设计、开发，也不展开首批用户招募、交付或复盘执行。

## 结论

MVP v0.1 要做的是一个最小闭环：

**资料采集 -> 账号定位 -> 内容主线 -> 选题池 -> 图文笔记生成 -> 发布反馈 -> 下一轮优化。**

它不是泛 AI 内容生成器，也不是代运营工具。

它必须包含内容生成，否则产品不闭环；但内容生成必须基于前面的定位、选题、用户资料和平台表达约束，不能变成泛泛写文案。

## 产品一句话

帮宠物品牌和个人 IP 完成小红书账号定位，并生成第一批可发布测试的图文笔记。

## 当前 MVP 用户

### 样本 A：宠物用品品牌老板

用户目标：

- 在小红书建立品牌认知；
- 讲清楚商品卖点和使用场景；
- 用内容验证用户兴趣、收藏、评论和购买意向。

产品边界：

- 不承诺销售；
- 不承诺转化率；
- 不做店铺运营；
- 不做广告投放。

### 样本 B：个人 IP

用户目标：

- 明确账号定位；
- 建立持续发布的内容主线；
- 用内容验证关注、评论、私信和互动意向。

产品边界：

- 不承诺涨粉；
- 不承诺爆款；
- 不承诺平台推荐；
- 不做个人 IP 陪跑课。

## MVP 产品闭环

### Step 1：资料采集

用户填写基础资料。

共同资料：

- 用户类型；
- 账号/品牌名称；
- 当前小红书账号或截图；
- 目标用户；
- 当前内容问题；
- 对标账号；
- 内容禁区；
- 可提供素材；
- 发布后的目标动作。

宠物品牌额外资料：

- 品牌定位；
- 主推商品；
- 商品卖点；
- 适用宠物和使用场景；
- 购买渠道；
- 品牌信任来源。

个人 IP 额外资料：

- 身份标签；
- 专业能力；
- 真实经历；
- 核心观点；
- 服务或产品；
- 不想呈现的人设边界。

### Step 2：账号定位

系统输出：

- 账号一句话定位；
- 目标用户；
- 核心卖点或专业优势；
- 差异化表达；
- 内容边界；
- 不建议做的方向。

验收标准：

- 定位必须能被一句话说清；
- 宠物品牌必须体现商品、场景和品牌信任；
- 个人 IP 必须体现经历、观点和专业能力；
- 不得出现销售、涨粉或爆款承诺。

### Step 3：内容主线

系统输出 3 条内容主线。

宠物品牌默认主线：

1. 场景种草；
2. 问题解决；
3. 品牌信任。

个人 IP 默认主线：

1. 经历故事；
2. 专业判断；
3. 方法拆解。

验收标准：

- 每条主线必须能持续生成选题；
- 每条主线必须说明适合什么用户、解决什么问题；
- 每条主线必须说明不适合怎么写。

### Step 4：对标参考

P0 不做自动抓取和平台数据采集。

系统只支持：

- 用户手动录入对标账号；
- 系统给出搜索关键词；
- 系统给出对标账号类型；
- 系统拆解可参考结构。

输出：

- 对标账号类型；
- 搜索关键词；
- 可学习的标题结构；
- 可学习的内容结构；
- 不可照搬点；
- 适合本账号的改写方向。

验收标准：

- 对标只用于结构参考；
- 不得输出一键搬运建议；
- 必须说明哪些内容不能照搬。

### Step 5：选题池

系统生成 20 个小红书选题。

每个选题包含：

- 选题标题；
- 所属内容主线；
- 目标用户；
- 内容目的；
- 推荐笔记类型；
- 建议正文长度；
- 适合的话题方向；
- 优先级。

内容目的可选：

- 建立认知；
- 解决疑问；
- 建立信任；
- 激发收藏；
- 引导评论；
- 引导私信；
- 商品种草；
- 关注互动。

验收标准：

- 至少生成 20 个选题；
- 每个选题必须绑定账号定位和内容主线；
- 宠物品牌选题必须能落到商品、场景或信任；
- 个人 IP 选题必须能体现经历、观点或专业能力。

### Step 6：图文笔记生成

系统基于选题生成 3 篇小红书图文笔记。

每篇笔记必须包含：

- 标题；
- 封面文案；
- 封面图建议；
- 正文；
- 正文字数限制；
- 配图建议；
- 推荐话题；
- 评论引导；
- 发布观察点。

#### 标题要求

- 默认不超过 20 个字；
- 不使用绝对化、夸大化表达；
- 不直接复制对标账号标题。

#### 正文字数限制

MVP 内置 3 档建议长度：

| 档位 | 建议字数 | 适合内容 |
| --- | --- | --- |
| 短笔记 | 300-500 字 | 轻种草、观点、互动 |
| 标准笔记 | 600-900 字 | 经验分享、问题解决、产品场景 |
| 长笔记 | 1000-1500 字 | 案例复盘、深度拆解、专业内容 |

说明：

- 这里是产品内的生成约束，不作为平台硬性规则；
- 系统应显示目标字数、当前字数和是否超出建议范围；
- 用户可以手动改短或改长。

#### 封面图建议

P0 不自动生成图片，只输出拍摄或制作建议。

每篇笔记输出：

- 封面画面主体；
- 画面构图；
- 适合实拍、产品图、截图、文字封面还是人物出镜；
- 封面情绪；
- 是否需要露产品、露人或露使用场景。

#### 配图建议

每篇笔记输出 3-6 张配图建议。

宠物品牌可选类型：

- 产品实拍；
- 宠物使用场景；
- 使用前后对比；
- 细节特写；
- 用户痛点场景；
- 包装或品牌质感图。

个人 IP 可选类型：

- 工作或生活场景；
- 观点金句图；
- 方法步骤图；
- 案例截图；
- 文档或白板截图；
- 个人出镜图。

#### 推荐话题

每篇笔记推荐 5-8 个话题。

话题分三类：

- 核心话题：与账号长期定位相关；
- 场景话题：与本篇笔记内容相关；
- 热门话题：与当前平台内容趋势相关，但必须和正文相关。

验收标准：

- 每个话题必须有推荐理由；
- 不强行蹭无关热点；
- 不输出与内容无关的热门话题；
- 宠物品牌话题应围绕宠物用品、养宠场景、具体痛点和商品使用；
- 个人 IP 话题应围绕专业领域、个人成长、方法经验和内容场景。

### Step 7：发布反馈

P0 不自动发布，只支持用户手动回填基础反馈。

回填字段：

- 发布时间；
- 浏览；
- 点赞；
- 收藏；
- 评论；
- 私信；
- 关注变化；
- 商品咨询或购买意向；
- 用户主观反馈；
- 截图或备注。

验收标准：

- 用户能记录至少 1 篇笔记的反馈；
- 宠物品牌重点观察收藏、评论、私信和商品咨询；
- 个人 IP 重点观察关注、评论、私信和互动质量；
- 数据只用于下一轮优化，不作为销售或涨粉承诺。

### Step 8：下一轮优化

系统根据发布反馈输出：

- 下一篇建议选题；
- 标题优化方向；
- 正文角度调整；
- 话题调整建议；
- 封面图和配图调整建议；
- 继续测试或暂停的内容方向。

验收标准：

- 优化建议必须基于定位、选题和用户反馈；
- 不只看点赞；
- 必须说明下一步为什么这样调整。

## AI 生成策略

### 输入优先级

1. 用户真实资料；
2. 用户产品、经历或案例；
3. 目标用户痛点；
4. 内容主线；
5. 对标账号结构；
6. 平台表达习惯；
7. 通用模板。

不要让通用模板覆盖用户真实信息。

### 输出约束

- 不直接搬运；
- 不伪造案例；
- 不承诺无法证明的效果；
- 不生成明显违规或夸大内容；
- 不使用“全网最”“必爆”“稳赚”等绝对化表达；
- 标题默认不超过 20 个字；
- 正文必须符合用户选择的字数档位；
- 话题必须与正文相关；
- 封面图和配图建议必须可执行；
- 输出必须保留人工编辑空间。

## 关键指标

当前不执行首批用户验证。以下指标只作为未来进入验证或产品化后的参考。

### 激活指标

- 完成资料填写；
- 生成账号定位；
- 生成 20 个选题；
- 生成至少 1 篇完整图文笔记。

### 内容质量指标

- 用户认为定位更清晰；
- 20 个选题里至少 70% 可继续修改或发布；
- 3 篇笔记草稿的修改量低于 40%；
- 每篇笔记都有可执行的封面图和配图建议；
- 每篇笔记都有相关话题和推荐理由。

### 发布反馈指标

- 用户愿意发布 1-3 篇笔记；
- 用户愿意回填基础数据；
- 宠物品牌能观察到商品咨询或购买意向；
- 个人 IP 能观察到关注、评论或私信意向。

## 验收标准

P0 通过标准：

- 可以完整录入一个宠物品牌或个人 IP 项目；
- 可以生成一份账号定位；
- 可以生成 3 条内容主线；
- 可以记录对标账号或给出对标搜索关键词；
- 可以生成 20 个选题；
- 可以生成 3 篇完整图文笔记；
- 每篇笔记标题默认不超过 20 个字；
- 每篇笔记正文符合所选字数档位，或明确提示超出；
- 每篇笔记包含封面图建议和 3-6 张配图建议；
- 每篇笔记包含 5-8 个推荐话题和推荐理由；
- 可以手动记录发布反馈；
- 可以输出下一轮优化建议。

## 风险与边界

### 风险 1：两个用户类型让产品变散

解决方式：共用产品流程，只在资料字段和输出模板里区分宠物品牌和个人 IP。

### 风险 2：内容生成变成泛 AI 文案

解决方式：每篇内容必须绑定账号定位、内容主线、选题目的和用户真实资料。

### 风险 3：用户误解为销售或涨粉承诺

解决方式：宠物品牌只看内容表达和购买意向，个人 IP 只看定位清晰和互动意向。

### 风险 4：热门话题变成强蹭热点

解决方式：每个话题必须和正文相关，并给出推荐理由。

### 风险 5：用户拿到文案仍然卡在配图

解决方式：每篇笔记必须输出封面图建议和配图建议，但 P0 不自动生成图片。

## 下一步

1. 检查产品方案决策稿和 PRD 阶段边界是否需要同步；
2. 用 1 个宠物品牌样本和 1 个个人 IP 样本跑通文档层输出；
3. 根据样本结果再决定是否进入真实用户测试、产品设计或开发。
