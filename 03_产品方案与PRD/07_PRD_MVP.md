# 小红书定位与内容验证助手 - MVP v0.2 PRD

更新日期：2026-06-11

当前状态：PRD 草案。

说明：本文用于固化当前 MVP 产品功能方案。当前只到产品需求文档，不进入产品设计、开发，也不展开首批用户招募、交付或复盘执行。

## 结论

MVP v0.2 不再按“一次性交付包”设计，而是按一个可反复使用的内容生产工作台设计。

核心目标：

**让用户每次登录后，都能基于自己的项目资料，产出 3 篇能发的小红书图文笔记，并通过发布反馈持续优化下一轮生成。**

产品划分为 5 个区域：

1. 登录；
2. 项目管理；
3. 资料库；
4. 内容生产区；
5. 数据反馈。

## 产品一句话

帮宠物品牌和个人 IP 保存长期资料，并每次生成 3 篇可发布测试的小红书图文笔记。

## MVP 用户

### 样本 A：宠物用品品牌老板

用户目标：

- 在小红书建立品牌认知；
- 讲清楚商品卖点和使用场景；
- 用内容验证用户兴趣、收藏、评论和购买意向。

产品边界：

- 不承诺销售；
- 不承诺转化率；
- 不做店铺运营；
- 不做广告投放。

### 样本 B：个人 IP

用户目标：

- 明确账号定位；
- 建立持续发布的内容主线；
- 用内容验证关注、评论、私信和互动意向。

产品边界：

- 不承诺涨粉；
- 不承诺爆款；
- 不承诺平台推荐；
- 不做个人 IP 陪跑课。

## 产品主流程

首次使用：

**登录/注册 -> 创建项目 -> 选择项目类型 -> 初始化资料 -> 生成定位和内容主线 -> 生成本次 3 篇图文笔记。**

后续使用：

**登录 -> 进入项目 -> 查看资料库 -> 新建生成任务 -> 生成 3 篇图文笔记 -> 保存任务历史 -> 回填发布反馈 -> 获得下一轮优化建议。**

核心原则：

- 资料库是长期资产；
- 项目类型初始化后不可更改；
- 内容生产区每次只负责生成本轮 3 篇图文笔记；
- 数据反馈区只做手动记录和优化建议，不自动抓取平台数据。

## 信息架构

### 区域 1：登录

作用：识别用户，保存项目、资料、生成记录和反馈。

P0 必做：

- 用户注册；
- 用户登录；
- 用户退出；
- 登录后进入个人工作区；
- 保存用户项目和历史数据。

P0 登录方式建议：

- 手机号 + 验证码；
- 或邮箱 + 密码。

二选一即可，P0 不需要同时做多种登录方式。

暂不做：

- 微信登录；
- 小红书账号授权；
- 会员套餐；
- 支付；
- 团队权限；
- 邀请协作；
- 多角色后台。

验收标准：

- 用户能注册并登录；
- 用户重新登录后能看到自己的项目；
- 不同用户之间数据隔离；
- 退出登录后不能查看原工作区数据。

### 区域 2：项目管理

作用：管理内容项目，决定项目使用哪套资料字段和生成模板。

P0 必做：

- 新建项目；
- 选择项目类型；
- 查看项目列表；
- 进入项目；
- 修改项目名称；
- 删除项目。

项目类型：

- 宠物品牌；
- 个人 IP。

初始化后不可更改：

- 项目类型；
- 项目底层模板；
- 核心业务场景分类。

初始化后可更改：

- 项目名称；
- 账号名称；
- 品牌介绍；
- 商品资料；
- 个人资料；
- 目标用户；
- 内容禁区；
- 对标账号；
- 素材条件。

选错类型的处理：

- 不允许直接修改项目类型；
- 用户可以新建项目；
- P1 可考虑“复制为新项目”。

验收标准：

- 用户至少能创建 1 个项目；
- 创建项目时必须选择宠物品牌或个人 IP；
- 项目创建后，项目类型不可编辑；
- 项目列表能显示项目名称、项目类型、最近生成时间。

### 区域 3：资料库

作用：沉淀长期资产，避免用户每次生成都重新填写。

资料库包含 4 类内容：

1. 账号资料；
2. 账号定位；
3. 长期资料；
4. 生成约束。

#### 3.1 账号资料

共同字段：

- 账号/品牌名称；
- 小红书账号链接或截图；
- 目标用户；
- 当前内容问题；
- 希望用户看完后的动作；
- 内容禁区；
- 可用素材；
- 对标账号。

宠物品牌字段：

- 品牌定位；
- 主推商品；
- 商品卖点；
- 适用宠物；
- 使用场景；
- 购买渠道；
- 品牌信任来源。

个人 IP 字段：

- 身份标签；
- 专业能力；
- 真实经历；
- 核心观点；
- 产品或服务；
- 人设边界；
- 可信任素材。

#### 3.2 账号定位

系统根据资料库生成，并允许用户编辑保存：

- 账号一句话定位；
- 目标用户；
- 核心卖点或专业优势；
- 差异化表达；
- 内容边界；
- 不建议做的方向。

验收标准：

- 定位必须能被一句话说清；
- 宠物品牌必须体现商品、场景和品牌信任；
- 个人 IP 必须体现经历、观点和专业能力；
- 不得出现销售、涨粉或爆款承诺；
- 用户编辑后，后续生成任务默认读取最新版定位。

#### 3.3 长期资料

长期资料用于每次生成任务复用。

包含：

- 内容主线；
- 对标参考；
- 话题偏好；
- 禁用词；
- 风格偏好；
- 可用素材；
- 用户案例或商品场景。

内容主线默认 3 条。

宠物品牌默认主线：

1. 场景种草；
2. 问题解决；
3. 品牌信任。

个人 IP 默认主线：

1. 经历故事；
2. 专业判断；
3. 方法拆解。

对标参考 P0 只做手动录入和结构拆解：

- 对标账号名；
- 链接或截图；
- 可学习标题结构；
- 可学习内容结构；
- 不建议照搬点；
- 适合本项目的改写方向。

暂不做：

- 自动抓取对标账号；
- 自动采集平台数据；
- 一键搬运爆款内容。

#### 3.4 生成约束

用于控制每次输出质量。

包含：

- 标题默认不超过 20 个字；
- 正文字数档位；
- 话题相关性要求；
- 封面图建议要求；
- 配图建议要求；
- 不得夸大承诺；
- 不得伪造案例。

验收标准：

- 资料库内容可编辑、可保存；
- 内容生产区每次生成必须读取资料库；
- 用户能看到资料库最后更新时间；
- 资料库缺关键字段时，内容生产区应提示补充。

### 区域 4：内容生产区

作用：用户每次来这里生成 3 篇能发的小红书图文笔记。

内容生产区包含 3 个模块：

1. 内容主线；
2. 生成任务；
3. 任务历史。

#### 4.1 内容主线

从资料库读取并展示。

用户可以：

- 查看 3 条长期内容主线；
- 选择本次生成要优先参考哪条主线；
- 查看每条主线适合什么用户、解决什么问题、不适合怎么写。

验收标准：

- 每个项目至少有 3 条内容主线；
- 每条主线能被生成任务引用；
- 每次生成的 3 篇笔记必须至少绑定 1 条内容主线。

#### 4.2 生成任务

用户每次新建一个生成任务。

任务输入：

- 本次内容目的；
- 选择内容主线；
- 正文字数档位；
- 笔记风格；
- 本次想强调的商品、经历或观点；
- 本次想避开的内容；
- 是否参考上一次反馈建议。

内容目的可选：

- 建立认知；
- 解决疑问；
- 建立信任；
- 激发收藏；
- 引导评论；
- 引导私信；
- 商品种草；
- 关注互动。

正文字数档位：

| 档位 | 建议字数 | 适合内容 |
| --- | --- | --- |
| 短笔记 | 300-500 字 | 轻种草、观点、互动 |
| 标准笔记 | 600-900 字 | 经验分享、问题解决、产品场景 |
| 长笔记 | 1000-1500 字 | 案例复盘、深度拆解、专业内容 |

每个任务固定输出：

**3 篇小红书图文笔记。**

每篇笔记包含：

- 标题；
- 封面文案；
- 封面图建议；
- 正文；
- 正文字数档位；
- 当前字数；
- 配图建议；
- 推荐话题；
- 评论引导；
- 发布观察点。

标题要求：

- 默认不超过 20 个字；
- 不使用绝对化、夸大化表达；
- 不直接复制对标账号标题。

封面图建议：

- 画面主体；
- 构图建议；
- 适合实拍、产品图、截图、文字封面还是人物出镜；
- 封面情绪；
- 是否需要露产品、露人或露使用场景。

配图建议：

- 每篇输出 3-6 张配图建议；
- 每张图说明图片内容、素材类型、拍摄/制作建议和作用。

推荐话题：

- 每篇推荐 5-8 个话题；
- 话题分为核心话题、场景话题、热门话题；
- 每个话题必须给推荐理由；
- 热门话题必须和正文相关，不强行蹭热点。

验收标准：

- 用户能新建生成任务；
- 每次任务固定生成 3 篇图文笔记；
- 3 篇笔记不得完全重复角度；
- 每篇笔记都能人工编辑；
- 每篇笔记都能保存为草稿；
- 每篇笔记必须绑定项目资料、定位和内容主线；
- 每篇笔记不得承诺销售、涨粉或爆款。

#### 4.3 任务历史

作用：保存用户每次生成的 3 篇笔记，支持持续使用。

任务历史展示：

- 任务名称；
- 创建时间；
- 对应内容目的；
- 生成的 3 篇笔记标题；
- 发布状态；
- 是否已填写反馈；
- 是否已生成优化建议。

笔记状态：

- 草稿；
- 已发布；
- 已反馈；
- 已归档。

验收标准：

- 用户重新登录后能查看历史任务；
- 用户能打开历史任务继续编辑；
- 用户能标记某篇笔记已发布；
- 用户能从历史任务进入发布反馈。

### 区域 5：数据反馈

作用：让产品从“生成器”变成“持续优化工具”。

P0 不自动抓取小红书数据，只支持手动回填。

#### 5.1 发布反馈

用户对单篇笔记填写：

- 发布时间；
- 浏览；
- 点赞；
- 收藏；
- 评论；
- 私信；
- 关注变化；
- 商品咨询或购买意向；
- 用户主观反馈；
- 截图或备注。

宠物品牌重点观察：

- 收藏；
- 评论；
- 私信；
- 商品咨询；
- 购买意向。

个人 IP 重点观察：

- 关注变化；
- 评论质量；
- 私信；
- 互动方向；
- 用户是否记住账号定位。

验收标准：

- 用户能为每篇已发布笔记填写反馈；
- 用户可以只填部分字段；
- 至少填写主观反馈或核心数据后，才能生成优化建议；
- 数据只用于下一轮优化，不作为销售或涨粉承诺。

#### 5.2 优化建议

系统根据资料库、任务内容和反馈数据输出：

- 下一轮内容方向；
- 下一次生成任务建议；
- 标题优化方向；
- 正文角度调整；
- 话题调整建议；
- 封面图和配图调整建议；
- 继续测试或暂停的内容方向。

验收标准：

- 优化建议必须说明依据；
- 不只看点赞；
- 必须关联原笔记、内容主线和反馈数据；
- 能被下一次生成任务引用。

## AI 生成策略

### 输入优先级

1. 资料库长期资料；
2. 账号定位；
3. 内容主线；
4. 本次生成任务要求；
5. 历史发布反馈；
6. 对标账号结构；
7. 平台表达习惯；
8. 通用模板。

不要让通用模板覆盖用户真实信息。

### 输出约束

- 不直接搬运；
- 不伪造案例；
- 不承诺无法证明的效果；
- 不生成明显违规或夸大内容；
- 不使用“全网最”“必爆”“稳赚”等绝对化表达；
- 标题默认不超过 20 个字；
- 正文必须符合用户选择的字数档位；
- 话题必须与正文相关；
- 封面图和配图建议必须可执行；
- 输出必须保留人工编辑空间。

## 关键指标

当前不执行首批用户验证。以下指标只作为未来进入验证或产品化后的参考。

### 激活指标

- 完成注册/登录；
- 创建项目；
- 完成资料库填写；
- 生成账号定位；
- 生成第一组 3 篇图文笔记。

### 生产指标

- 用户每次能成功生成 3 篇图文笔记；
- 每篇笔记都有标题、封面、正文、话题、配图建议；
- 用户能保存并再次打开历史任务；
- 用户对 3 篇笔记的修改量低于 40%。

### 反馈指标

- 用户愿意发布 1-3 篇笔记；
- 用户愿意回填基础反馈；
- 用户愿意基于反馈再生成下一轮 3 篇；
- 宠物品牌能观察到商品咨询或购买意向；
- 个人 IP 能观察到关注、评论或私信意向。

## 验收标准

P0 通过标准：

- 用户能注册、登录和退出；
- 用户能创建宠物品牌或个人 IP 项目；
- 项目类型创建后不可修改；
- 用户能保存资料库；
- 用户能生成并保存账号定位；
- 用户能生成并保存 3 条内容主线；
- 用户能新建生成任务；
- 每个生成任务固定产出 3 篇图文笔记；
- 每篇笔记标题默认不超过 20 个字；
- 每篇笔记正文符合所选字数档位，或明确提示超出；
- 每篇笔记包含封面图建议和 3-6 张配图建议；
- 每篇笔记包含 5-8 个推荐话题和推荐理由；
- 用户能查看任务历史；
- 用户能手动记录发布反馈；
- 系统能输出下一轮优化建议。

## 风险与边界

### 风险 1：登录让 MVP 变重

解决方式：P0 只做最小登录，用于保存用户项目、资料库、任务历史和反馈，不做会员、支付、团队和权限系统。

### 风险 2：项目类型不可更改导致用户选错

解决方式：创建项目时明确提示；选错后新建项目，P1 再考虑复制为新项目。

### 风险 3：资料库填写太重

解决方式：先收必填字段，允许后续补充；内容生产前只拦截真正影响生成质量的关键缺失项。

### 风险 4：内容生成变成泛 AI 文案

解决方式：每篇内容必须绑定资料库、账号定位、内容主线、本次任务和用户真实资料。

### 风险 5：用户误解为销售或涨粉承诺

解决方式：宠物品牌只看内容表达和购买意向，个人 IP 只看定位清晰和互动意向。

### 风险 6：用户拿到文案仍然卡在配图

解决方式：每篇笔记必须输出封面图建议和配图建议，但 P0 不自动生成图片。
