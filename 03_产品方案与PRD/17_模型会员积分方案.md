# 巴布 - 模型、会员与积分方案

- 更新日期：`2026-08-07`
- 产品版本：`MVP v0.9`
- 当前实现基线：`MVP v0.9 / v2026.08.07.3`
- 当前状态：产品与技术决策已进入交互原型，真实工程尚未实施
- 适用市场：中国大陆
- 首发平台：小红书

## 结论

巴布第一版采用“一套会员 + 月度赠送积分 + 额外积分包”的商业模型，配合“国内默认、海外高质量可选”的文字与图片双栈。账号和商品资料不限量，真正需要控成本的文字生成、图片生成、搜索和 AI 质检统一通过积分结算。

产品不向用户销售模型名称，也不承诺固定图片数量；对外表达统一为“AI 创作额度”。内部用可追溯账本将每次成功结果、积分扣减和真实成本关联起来。

## 1. 产品差异化

普通生成工具常从一次性提示词出发。巴布生成前必须读取：

1. 当前账号定位与目标用户；
2. 品牌、商品或个人 IP 资料；
3. 用户选择的内容主线或商品主线；
4. 当前账号历史笔记，用于减少重复并保持表达连续；
5. 近期公开信息的结构化搜索摘要；
6. 平台模板与内容安全规则。

资料不完整时允许继续生成并推断语气、受众偏好等软属性，但不得编造价格、规格、材质、认证、功效、品牌历史、销量或用户反馈等硬事实。

## 2. 模型方案

### 2.1 双栈模式

| 模式 | 默认用途 | 用户感知 | 处理规则 |
| --- | --- | --- | --- |
| 标准模式 | 国内文字与图片模型 | 默认选择，速度与成本稳定 | 国内链路处理 |
| 高质量模式 | 海外文字或图片模型 | 用户按任务主动开启，积分更高 | 首次开启前明确提示第三方处理并取得同意 |

文字与图片分别选择模式。例如，用户可以使用标准文字和高质量图片，不要求整次创作统一档位。

### 2.2 候选池与选择方式

国内文字候选：Qwen 3.7 Max、DeepSeek V4 Pro、Doubao Seed 2.1 Pro。

国内图片候选：Seedream 5.0 Lite、Seedream 4.5。

海外文字候选：GPT-5.6 Terra/Sol、Gemini 3.1 Pro Preview。

海外图片候选：Gemini 3.1 Flash Image。

候选名称只用于当前评测，不写死为上线承诺。正式主模型与备用模型必须通过同一批账号、商品和任务的盲测决定，并通过服务端别名配置切换。

候选核验入口（2026-08-07）：

- [DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing)
- [火山引擎大模型服务](https://www.volcengine.com/product/yunque)
- [Seedream 4.0-5.0 提示词指南](https://www.volcengine.com/docs/82379/1829186)

上线前必须重新核验模型状态、地区、价格、限流、数据条款和中转服务协议，不能只依赖本规划日期的页面。

### 2.3 文字生成链路

```text
任务参数
  -> 账号/商品/IP/历史上下文
  -> 一次近期搜索与结构化摘要
  -> Prompt Builder
  -> 文字模型
  -> 固定规则检查
  -> 按模式或风险触发 AI 审核与一次优化
  -> 保存只读结果
```

提示词分三层：

- 基础层：角色、事实边界、安全和输出结构；
- 任务层：小红书平台模板、主线、字数和篇数；
- 用户层：账号定位、商品/IP 优势、历史内容与搜索摘要。

### 2.4 搜索链路

- 搜索服务与生成模型解耦；
- 每个生成任务只搜索一次，1-5 篇笔记共享结果；
- 搜索结果先过滤、去重、摘要和结构化，不把大量原始网页直接塞给模型；
- 第一版使用官方 API 和公开搜索，不抓取平台页面；
- 可按主题和时效设置缓存，热点类默认不超过 24 小时；
- 搜索成本包含在文字积分中，不另设普通搜索收费项；
- 未来可新增高阶热点分析能力并单独定价。

### 2.5 质量检查

固定规则至少检查：

- 标题、正文、话题数量和结构；
- 账号定位与商品资料中的硬事实；
- 绝对化承诺、违规词和高风险行业；
- 与当前账号历史选题的明显重复；
- 小红书表达是否自然，是否出现通用模板腔。

标准模式默认执行规则检查；规则异常、事实风险或低分结果触发轻量 AI 审核。高质量模式固定执行 AI 审核与最多一次自动优化。

内部建议评分维度：账号匹配 25%、商品/IP 融合 20%、真实感 20%、小红书表达 15%、差异化 10%、安全合规 10%。评分不直接向用户展示。

### 2.6 图片生成链路

```text
商品图片/账号视觉资料
  -> 视觉分析
  -> 图片类型与用途
  -> 图片 Prompt
  -> 图片模型
  -> 尺寸与视觉质量检查
  -> 自有存储
  -> 可选中文标题叠加
```

图片分为：

- 内容场景图：允许围绕主线进行视觉创意；
- 商品展示图：必须保持商品主体、颜色和关键结构，无法保证时不应输出为真实商品图。

统一比例为 3:4，默认 1080 x 1440。每次生成 1-6 张。封面可使用系统文字层叠加中文标题，正文和商品图片默认不加文字；不让图片模型直接生成中文。

## 3. 会员方案

### 3.1 定价

| 会员周期 | 价格 | 月均价格 | 赠送积分 |
| --- | ---: | ---: | ---: |
| 月会员 | 88 元 | 88 元 | 每个有效月 1000 |
| 季度会员 | 228 元 | 76 元 | 每个会员月发放 1000 |
| 年会员 | 688 元 | 约 57.3 元 | 每个会员月发放 1000 |

三档使用同一套权益，不拆功能等级。会员期内账号、商品和个人 IP 资料不限添加数量，但生成任务仍受积分、单次数量、并发和安全限制。

### 3.2 会员状态

- 不提供自动续费；
- 到期前 7、3、1 天提醒；
- 到期后停止新的文字和图片生成；
- 历史笔记和图片继续可查看、复制和下载；
- 购买积分在会员到期后冻结，续费后恢复，不因冻结延长有效期；
- 非会员可查看真实案例和功能说明，但不能免费生成。

## 4. 积分方案

### 4.1 发放与有效期

- 会员赠送积分在每个会员月开始时发放 1000，未用完部分在该会员月结束时清零；
- 季度和年会员仍按月发放，避免一次性透支成本；
- 购买积分有效期 12 个月；
- 扣减顺序：当月赠送积分优先，其次按购买积分最早到期顺序；
- 积分不可转赠、提现或兑换现金。

### 4.2 积分包

| 积分 | 价格 | 每积分价格 |
| ---: | ---: | ---: |
| 300 | 29 元 | 约 0.097 元 |
| 1000 | 79 元 | 0.079 元 |
| 3000 | 199 元 | 约 0.066 元 |

只有有效会员可以购买和使用积分包。

### 4.3 扣费规则

| 能力 | 标准模式 | 高质量模式 |
| --- | ---: | ---: |
| 文字笔记 | 3 积分/篇 | 6 积分/篇 |
| 内容场景图 | 10 积分/张 | 20 积分/张 |
| 商品展示图 | 20 积分/张 | 40 积分/张 |

- 创建任务时冻结预计积分，成功后按实际结果结算，多余冻结积分释放；
- 文字单次生成 1-5 篇，一次任务内提供一次免费重新生成；
- 免费重新生成仍需经过防重复和质量检查，但不再次扣积分；
- 第二次及之后重新生成按成功篇数扣费；
- 图片按成功返回并存储的张数扣费；
- 超时、供应商错误、搜索失败或系统错误不扣费，已冻结积分自动返还；
- 用户主动取消且模型尚未开始时全部解冻，已产生不可逆供应商成本时由退款规则处理。

### 4.4 使用示例

`120` 篇标准笔记加 `60` 张标准内容场景图，约消耗 `960` 积分。该示例只用于内部成本校验，不对外承诺会员每月固定可生成多少篇或多少张，因为用户的文字、图片类型和质量模式组合不同。

## 5. 支付方案

- PC 端展示微信支付和支付宝二维码；
- 订单创建后二维码有明确有效期，并支持刷新；
- 只有服务端收到并验证支付回调后才能发放会员或积分；
- 同一支付回调必须幂等，不能重复发放；
- 支付取消、超时、失败、延迟到账和重复支付都有明确状态；
- 会员订单与积分订单分别记录商品、金额、支付渠道、交易号和到账时间；
- 首版不做自动续费、免密支付或复杂优惠券。

## 6. 内容历史与内部记录

### 6.1 用户可见历史

本阶段采用历史方案 A：只把生成结果作为用户内容资产。

按账号保存并展示：

- 标题；
- 正文；
- 话题；
- 生成图片；
- 生成时间。

结果保持只读，用户可复制标题、正文与话题，并下载图片。第一版不要求用户维护草稿、状态或编辑版本。

### 6.2 内部运行记录

单独保存最小可追溯信息：

- 任务 ID、账号 ID、模型别名与供应商请求 ID；
- Prompt 版本、搜索摘要版本和质量检查结果；
- Token、图片张数、耗时、重试与真实成本；
- 冻结、扣减、返还的积分流水；
- 错误码和有限期日志。

内部记录不保存完整账号/商品快照、完整 Prompt 或原始搜索网页，不作为可检索的内容知识库。普通运行日志建议保留 30 天，搜索正文只按缓存时效保留；订单、积分账本和依法需要保留的对账信息按单独财务规则处理。

内部记录不在创作历史中展示，不跨用户或跨账号混用，不用于公共模型训练。未来 RAG 必须另行取得用户授权并定义删除、导出和保留规则。

## 7. 内容发布边界

第一版不绑定小红书账号，不保存平台密码或 Cookie，也不自动发布。用户只做：

1. 复制标题；
2. 复制正文与话题；
3. 下载图片；
4. 自行进入小红书发布。

后续可增加抖音和微信公众号模板，但需要独立的篇幅、语气、封面和审核规则，不能简单复用小红书结果。

## 8. 风险与防线

### 成本

- 目标综合毛利率不低于 65%；
- 年会员月均收入约 57.3 元，月均直接成本目标不超过 20 元；
- 建议成本上限：图片 12 元、文字 2 元、搜索 3 元、存储支付与其他 3 元；
- 成本超线时优先调整高成本任务积分或月度赠送量，不静默降低生成质量。

### 合规

第一版不服务以下生成需求：医疗诊断、处方、药品功效，保健品治疗承诺，证券、投资、加密资产收益承诺，以及替代专业律师的法律结论。普通行业继续拦截“保证、最好、第一、根治、100% 有效”等绝对化表达。

### 数据

- 首次启用海外高质量模式前明确说明第三方处理；
- 不跨账号引用历史资料；
- 用户粘贴的 3-10 篇历史内容只用于当前账号生成，不逐字复制；
- 用户删除账号时，用户资产与内部运行记录按保留政策分别处理。

## 9. 上线验收

### 模型

- 3-5 名真实试用者完成 30-50 个盲测任务；
- 账号贴合、商品/IP 融合、事实准确、自然表达、直接可用性和多样性均有评分；
- 至少 80% 输出可直接使用或只需极少修改；
- 标准与高质量模式的平均耗时、成功率和成本均达到预算。

### 账务

- 任意一次积分变化可追溯到任务或订单；
- 重复回调不重复发放，重复消费请求不重复扣费；
- 失败任务自动返还冻结积分；
- 会员到期后的冻结、续费后的恢复和购买积分到期均正确；
- 账面金额、支付渠道金额和发放权益可对账。

### 产品

- 生成前明确展示预计积分；
- 积分不足时给出续费或购买积分入口，不丢失当前任务；
- 海外模式首次开启有明确同意步骤；
- 用户能在历史中查看和复制笔记、下载图片；
- 页面不暗示已自动发布或保证增长结果。

## 10. 后续预留

- 付费第三方社媒数据服务，作为独立 `SocialProvider` 接入；
- 抖音和微信公众号平台模板；
- 用户授权后的历史内容检索增强；
- 更精细的图片商品一致性检查；
- 基于真实成本与留存数据调整新周期权益。

不在第一版预留的复杂度：多套会员、团队席位、账号共享治理、模型微调、知识图谱、自动发布和自动多模型竞价。
