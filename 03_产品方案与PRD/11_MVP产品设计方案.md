# 巴布 - MVP v0.8 产品设计方案

- 更新日期：2026-08-07
- 产品版本：`MVP v0.8`
- 里程碑版本：`v2026.08.07.2`
- 当前状态：产品设计基线
- 对应需求：`07_PRD_MVP.md`
- 对应原型：`../04_可视化原型/index.html`

## 结论

MVP v0.8 将登录后的内容任务收口为统一的三列工作台：左侧一级菜单决定当前模块，中栏管理当前上下文对象，右侧完成任务。对话、创作和账号共享这一空间关系；个人中心作为低频账户页，保留左侧菜单并使用整块右侧区域。

本版重点不是增加更多功能，而是让用户清楚三件事：当前在哪个模块、正在处理哪个对象、下一步该做什么。

## 设计原则

1. 桌面端优先，当前不做手机端专门适配。
2. 一级模块固定为对话、创作、账号，避免页面内部重复导航。
3. 中栏只放列表、搜索、新建和切换，复杂操作放在右侧。
4. 右侧使用可用宽度，不把主要内容压在左半区。
5. 创作结果直接供用户查看，不增加状态、编辑和保存流程。
6. 图片是单篇笔记的二段动作，不做独立图片设计器。
7. 每个深层状态都保留明确的返回路径。
8. 品牌红只用于主操作和选中态，薄荷绿只用于少量完成反馈。
9. 账户与支付相关界面必须区分已实现能力和仅预留入口。

## 视觉方向

界面延续巴布现有品牌系统：

- 墨黑 `#111317`：标题、正文和主要图标；
- 珊瑚红 `#FF4D3D`：主按钮、选中态和重点反馈；
- 薄荷绿 `#22C5A3`：完成和成功提示；
- 暖白 `#FAF8F6`：页面与工作区底色；
- 浅灰：分隔线、次级信息和未选控件。

界面气质应是安静、实用、便于反复操作的工作台，不使用营销页式大标题、装饰卡片、渐变球或大面积单色铺陈。

## 全局布局

### 三列结构

| 区域 | 建议宽度 | 设计职责 |
| --- | --- | --- |
| 一级菜单 | 固定窄栏 | Logo、对话、创作、账号、积分和个人中心 |
| 上下文栏 | 固定中栏 | 对话列表或账号列表、搜索和新建入口 |
| 工作区 | 自适应 | 当前模块的核心任务和详情 |

布局规则：

- 三列从左到右连续排列，不用外层描边框住整个工作区；
- 中栏与工作区用背景和轻分隔线区分；
- 工作区内容保留稳定左右边距，并根据屏幕宽度扩展；
- 账号页、创作页和创作历史使用同一组右侧内容宽度规则；
- 固定格式控件使用明确网格或最小宽度，动态内容不能改变整体列宽；
- 当前支持的桌面视口不得出现横向滚动条。
- 个人中心隐藏中间上下文栏，右侧工作区从一级菜单之后开始连续展开。

### 一级菜单

- 当前模块使用浅红底和品牌红图标；
- 未选模块只显示黑色或灰色图标与文字；
- 对话、创作、账号都可直接切换；
- 不在右侧顶部重复显示一级模块标签；
- Logo 可回到首页；
- 底部保留积分和个人中心入口。

## 对话设计

### 中栏

从上到下包含：

1. 标题“对话”；
2. 历史对话搜索框；
3. “新建对话”主按钮；
4. 按时间分组的历史对话列表，不额外显示“历史对话”栏目标题。

对话列表项展示：

- 标题；
- 一行摘要；
- 最近更新时间；
- 当前对话选中态。

所有会话项使用相同固定高度，标题、摘要和时间在同一网格中稳定对齐。

列表密度应支持快速扫描，不把每个会话做成独立浮动卡片。

### 右侧聊天区

结构：

- 顶部：居中的对话标题，不重复显示更新时间；
- 中部：消息列表或新对话空状态；
- 底部：固定输入区、发送按钮和必要提示。

空状态：

- 使用巴布现有应用图标；
- 标题为“今天想一起做什么？”；
- 快捷问题使用两列紧凑按钮；
- 点击快捷问题只填入输入框，不自动发送。

消息状态：

- 用户消息右对齐；
- 助手消息左对齐并显示巴布图标；
- 发送后展示三点等待反馈；
- 回复出现后消息区滚动到最新位置；
- 输入为空时发送按钮禁用。
- 输入框聚焦时不出现额外描边，也不改变输入区尺寸。

宽度规则：

- 对话正文、顶部标题和输入区共享内容最大宽度；
- 宽屏最大内容宽度为 1400px；
- 保持左右可读边距，避免消息横跨整块工作区。

## 账号设计

### 中栏

- 标题“账号”；
- 账号搜索；
- 新建账号按钮；
- 多账号列表；
- 每项显示头像、昵称、账号类型、小红书号和内容数量。

### 账号详情

右侧使用连续页面结构，不把整个区域套在边框卡片中。

顶部信息：

- 头像；
- 昵称；
- 账号类型；
- 小红书号；
- 简介和公开数据；
- 单一“编辑”入口。

内容区域：

- 品牌账号使用“账号资料 / 商品”标签；
- 个人 IP 使用“账号资料 / 产品或服务”标签；
- 摘要信息、目标用户、内容方向和最近内容采用清晰分栏；
- 商品标签横向排列，选中商品后展示图片、定价、卖点和场景；
- 右侧主内容宽度、起始位置和创作页保持一致。

### 创建账号

品牌账号三步：

1. 账号；
2. 品牌；
3. 商品。

个人 IP 两步：

1. 账号；
2. IP。

交互规则：

- 顶部先选择账号类型；
- 切换类型后重置到第一步；
- 进度、标题和底部按钮随类型变化；
- 品牌商品可增加多组，每组上传 1-3 张；
- 底部操作区不使用浮动卡片或明显外框；
- 表单内容滚动时，操作按钮不能遮挡字段。

## 创作设计

### 中栏

- 标题“创作”；
- 账号搜索；
- 新建账号入口；
- 多账号列表；
- 当前创作账号选中态。

中栏只负责账号上下文，不承载重复生成设置。

### 右侧工作区

工作区按任务顺序连续排列：

1. 选择创作主线；
2. 生成设置；
3. 笔记预览。

顶部只保留必要的“创作历史”入口，不重复显示一级菜单切换。

### 创作主线

第一层使用分段控制：

- 内容主线；
- 商品主线。

内容主线：

- 横向展示三个候选方向；
- 每项包含名称和简短说明；
- 单选，默认第一项。

商品主线：

- 横向展示商品候选；
- 每项必须包含商品第一张图和商品标题；
- 图片使用固定尺寸和 `object-fit: cover`；
- 单选后浅红底和品牌红边线反馈。

### 生成设置

设置使用一行三列：

1. 正文字数；
2. 生成笔记数；
3. 生成按钮。

正文字数内部三个选项横向排列。两个参数组顶端对齐，标题和控件之间保持一致间距；右侧剩余空间应被合理利用，不能把全部控件压在左侧。配图数量只在单篇详情中选择，不在生成设置重复出现。

### 笔记预览

- 生成前显示简洁空状态；
- 生成后显示 1-5 行笔记；
- 每行包含序号、标题、正文摘要和话题；
- 整行可点击；
- 不显示状态列；
- 不提供编辑、保存或发布按钮。

## 创作历史设计

- 页面标题使用“创作历史”；
- 中栏继续保留账号选择；
- 右侧展示当前账号名称、历史笔记数量和笔记列表；
- 取消任务参数汇总表和新建任务按钮；
- 每行展示封面、标题、摘要、话题、时间和“查看详情”；
- 点击整行进入单篇详情；
- 空账号或无记录时显示对应空状态。

历史列表和创作页使用相同内容起点、最大宽度和左右间距。

## 笔记详情设计

### 顶部

- 左侧为“返回”；
- 同行紧凑展示内容主线和生成参数摘要；
- 不重复显示创作账号，因为中栏已明确当前账号；
- 不使用整条外框包围顶部区域。

### 内容区

采用左右分栏：

- 左侧：只读标题、正文和话题；
- 右侧：生成配图。

规则：

- 内容区整体靠近左侧内容起点；
- 左栏承担主要阅读宽度；
- 右栏有足够宽度展示三列图片；
- 标题、正文和话题不使用输入框、文本域或可编辑样式；
- 不显示保存按钮、编辑入口和状态标签。

### 配图区

顶部控制：

- 图片数量下拉框，1-6 张；
- “生成配图”按钮；
- 已有结果时按钮可显示“重新生成”。

状态：

- 初始：提示选择数量并生成；
- 加载：显示加载反馈和等待文案；
- 成功：展示对应数量图片；
- 失败：保留文字内容并提供重试。

图片网格：

- 宽屏每行最多三张；
- 每张图比例稳定，标题在图下方；
- 1-2 张不拉伸填满整行；
- 4-6 张自然换到第二行；
- 图片加载不能导致工作区横向溢出。

## 个人中心设计

### 布局

- 左侧一级菜单保持可见并标记个人中心选中态；
- 中间上下文栏隐藏；
- 右侧使用连续整页工作区，不套多余外层卡片；
- 页面标题为“个人中心”，退出登录位于右上角；
- 顶部标签依次为“注册信息、充值、消费记录”，后两项显示“即将开放”且不可点击。

### 注册信息

- 展示当前登录邮箱；
- 修改密码使用当前密码、新密码和确认新密码三个输入框；
- 宽屏横向排列，较窄桌面视口改为单列；
- 错误和成功反馈紧邻修改按钮，不弹出额外页面。

### 退出登录

- 点击退出登录后显示居中确认弹窗；
- 弹窗只询问“是否确定退出登录？”；
- “否”关闭弹窗并停留当前页；
- “是”退出本地登录状态并回到未登录首页。

## 组件规范

| 组件 | 使用位置 | 规则 |
| --- | --- | --- |
| 图标按钮 | 发送、返回、搜索等熟悉操作 | 使用本地 Lucide 图标并提供 `title` 或 `aria-label` |
| 主按钮 | 新建、生成、保存账号 | 珊瑚红背景，单页只突出一个主要动作 |
| 分段控制 | 内容/商品主线 | 同组单选，选中态明确 |
| 选项组 | 正文字数 | 宽度稳定，标签可换行但不改变外层布局 |
| 步进器 | 生成笔记数 | 1-5，减号、数字、加号固定宽度 |
| 下拉框 | 图片数量 | 1-6 张 |
| 列表行 | 对话、账号、笔记历史 | 适合扫描，不嵌套卡片 |
| 只读字段 | 笔记详情 | 使用文本排版，不伪装为可编辑输入框 |

## 关键状态

| 模块 | 状态 |
| --- | --- |
| 登录 | 未登录、登录中、失败、成功 |
| 对话 | 空白、已有消息、等待回复、搜索无结果 |
| 账号 | 无账号、多账号、创建中、详情、编辑 |
| 创作 | 未生成、生成中、结果、账号无资料 |
| 历史 | 有笔记、无笔记、详情 |
| 图片 | 未生成、生成中、生成成功、失败 |
| 个人中心 | 注册信息、密码校验失败、修改成功、退出确认 |

## 验收标准

### 布局

- 三个一级模块都清晰呈现左侧菜单、中栏和右侧工作区；个人中心清晰呈现左侧菜单和整块右侧区域；
- 账号页、创作页和历史页的右侧内容起点与宽度规则一致；
- 对话内容宽度扩展到 1400px 上限；
- 桌面视口无横向滚动、内容遮挡和无意义空白集中。

### 交互

- 对话的新建、搜索、历史切换、快捷问题、发送和等待状态可走通；
- 账号的搜索、切换、品牌三步和个人 IP 两步可走通；
- 创作的账号切换、主线切换、字数和篇数设置、生成和预览可走通；
- 创作历史按账号切换，列表可进入详情；
- 详情只读，1-6 张图片生成有加载和结果状态。
- 个人中心能查看登录邮箱、校验修改密码并完成退出登录二次确认。

### 一致性

- 不出现“任务历史”“内容变成图片”“保存笔记”“编辑笔记”等旧版当前操作；
- 不在右侧顶部重复一级菜单；
- 不把页面分区做成相互嵌套的卡片；
- 页面颜色、圆角、边框和字号遵循巴布现有视觉规范。

## 当前边界

- 当前只实现本地静态原型；
- 对话、笔记和图片结果均为演示数据或本地交互；
- 密码修改、退出登录、充值和消费记录均为原型界面，不代表真实认证或账务系统可用；
- 不包含真实后端、云端持久化、AI 模型、小红书授权或自动发布；
- 正式工程开发前需重新确认权限、数据结构、模型成本和平台合规。

## 下一步

1. 用真实任务走查三列结构和四段核心流程；
2. 记录用户是否理解对话和创作的职责差异；
3. 记录只读笔记是否满足使用需求；
4. 根据走查结果决定是否进入工程化。
