## 结论

低保真原型 v0.3 只验证一件事：

**用户能否从登录进入项目，完成资料库，在内容管理选择场景卡并手动提供素材，先看到诊断判断，再拿到 3 篇可发布检查的小红书笔记，并对单篇笔记生成图片。**

原型形态建议：

- 信息密度适中，像一个内容工作台；
- 不做营销首页；
- 不做复杂仪表盘；
- 不做自动发布、平台爬取、自动解析、复杂图片编辑器；
- 重点突出“下一步该做什么”和“这篇笔记能不能发”。

## 设计 Brief

产品目标：

帮助一人公司、品牌主和个人 IP 保存长期资料，通过场景卡完成诊断判断，每次生成 3 篇能发的小红书笔记，并支持生成配图或把内容变成图片。

当前样本：

- 品牌 - 宠物用品；
- 个人 IP - 知识分享。

视觉来源：

- 参考 Reelmate / 万兴剧厂的深色 AI 创作工作台气质；
- 保留清晰表单和内容管理效率，不完整照搬影视工具的大图视觉；
- 方向为深色背景、轻侧栏、紫色主按钮、半透明卡片和中央主行动。

交互级别：

- 本地可点击原型；
- 关键按钮、状态和跳转关系要明确；
- 不要求真实表单校验或真实 AI 生成。

## 全局导航

登录页单独存在。登录成功后，再进入工作台结构。

左侧主菜单只保留 3 个：

- 项目管理；
- 内容管理；
- 数据反馈。

主菜单与内部页面关系：

- 项目管理：项目管理页、创建项目页、项目首页、资料库页、定位与内容主线页；
- 内容管理：内容管理页、场景卡素材输入状态、诊断结果状态、任务历史页、笔记详情/编辑页、生成图片；
- 数据反馈：数据反馈页、优化建议页。

原则：

- 登录页不出现在左侧菜单；
- 创建项目、资料库、定位与主线不是一级菜单，只能从项目管理内部进入；
- 任务历史、笔记详情不是一级菜单，只能从内容管理内部进入；
- 优化建议不是一级菜单，只能从数据反馈内部进入。

顶部区域：

- 当前项目名称；
- 项目大类；
- 细分方向；
- 资料库状态；
- 用户入口。

全局状态提示：

- 资料未完成；
- 定位未生成；
- 可生成内容；
- 有待反馈笔记；
- 有优化建议可查看。

## 登录后数据判断逻辑

### 首次登录

登录成功后：

1. 初始化用户工作区；
2. 进入项目管理页；
3. 项目管理为空；
4. 用户先添加项目；
5. 项目保存成功后，项目管理新增一条项目记录；
6. 项目记录中必须有“资料库”按钮；
7. 点击资料库后进入资料库页；
8. 资料库为空，用户需要保存账号资料、账号定位、长期资料和生成约束；
9. 资料库保存完成后，内容管理才可用；
10. 数据反馈可以进入，但在没有生成记录前为空。

### 非首次登录

登录成功后先判断项目管理是否有数据。

如果项目管理没有数据：

- 展示项目管理空状态；
- 引导添加项目。

如果项目管理有数据：

- 继续判断资料库是否有账号数据。

如果资料库没有账号数据：

- 项目管理显示已有项目记录；
- 项目记录突出“资料库”按钮；
- 内容管理不可用；
- 数据反馈为空。

如果项目管理和资料库都有数据：

- 继续判断是否有生成记录。

如果没有生成记录：

- 内容管理可用；
- 任务历史为空；
- 数据反馈为空。

如果已有生成记录：

- 任务历史展示生成记录；
- 再判断数据反馈是否有数据；
- 没有反馈数据时展示空状态；
- 有反馈数据时展示反馈记录和优化建议入口。

## 1. 登录/注册页

### 页面目标

单独完成登录。登录成功后再进入项目管理页，不在登录页展示工作台导航。

### 页面布局

上半区：

- 产品名称；
- 一句话说明；
- 登录方式切换。

中间表单：

- 手机号或邮箱；
- 验证码或密码；
- 登录/注册按钮。

底部提示：

- 登录只用于保存项目和生成历史；
- 不需要授权小红书账号。

### 主要按钮

- 登录；
- 注册；
- 获取验证码；
- 忘记密码。

### 页面状态

- 未输入；
- 输入不完整；
- 验证中；
- 登录失败；
- 登录成功。

### 跳转

- 登录成功 -> 项目管理页；
- 首次登录 -> 项目管理空状态；
- 非首次登录 -> 按项目、资料库、生成记录和反馈数据逐层判断状态。

### 页面目标

判断用户是否已有项目数据；没有项目时引导创建项目，有项目时展示项目记录。

### 页面布局

顶部：

- 页面标题：项目管理；
- 新建项目按钮。

项目记录：

- 项目名称；
- 项目大类；
- 细分方向；
- 资料库完成度；
- 最近生成时间；
- 最近反馈状态；
- 资料库按钮；
- 进入项目按钮。

空状态：

- 文案：先创建一个小红书内容项目；
- 主按钮：新建项目。

### 筛选/展示

- 全部；
- 品牌；
- 个人 IP。

### 页面状态

- 无项目；
- 有项目但资料未完成；
- 有项目且可生成；
- 项目有待反馈笔记。

### 跳转

- 新建项目 -> 创建项目页；
- 资料库 -> 资料库页；
- 进入项目 -> 项目首页。

## 3. 创建项目页

### 页面目标

初始化项目，并确认不可更改的项目大类。

### 页面布局

步骤 1：选择类型

- 品牌；
- 个人 IP；
- 项目类型保存后不可更改；
- 选错类型需要重新新建项目。

步骤 2：项目基础信息

- 项目名称；
- 账号/品牌名称；
- 小红书账号链接或截图。

步骤 3：细分方向

- 品牌：宠物、餐饮、美妆、母婴、本地生活、其他；
- 个人 IP：知识分享、美妆、育儿、职场、情感、其他。

页面布局要求：

- 不使用三栏并排；
- 按“选择类型 -> 基础信息 -> 细分方向”由上往下平铺；
- 保存按钮放在页面最底部；
- 底部保存按钮表示保存所有项目初始化信息。

### 主要按钮

- 保存所有。

### 页面状态

- 未选择项目大类；
- 已选择品牌；
- 已选择个人 IP；
- 未选择细分方向；
- 创建成功；
- 创建失败。

### 跳转

- 创建成功 -> 项目管理页，并新增一条项目记录；
- 取消 -> 项目管理页。

四个摘要模块：

- 账号定位摘要；

### 主要按钮

- 完善资料库；
- 生成定位和主线；
- 进入内容管理；
- 填写反馈；
- 查看优化建议。

### 页面状态

- 新项目；
- 资料未完成；
- 资料已完成；
- 可生成内容；
- 有任务历史；
- 有反馈建议。

### 跳转

- 填写反馈 -> 发布反馈页；

## 5. 资料库页

### 页面目标

沉淀长期资料，让后续生成不用反复填写。

### 页面布局

页面上方标签页：

- 基础资料；
- 品牌资料或个人 IP 资料；
- 内容偏好；
- 素材条件；
- 对标参考；
- 生成约束。

交互要求：

- 每个分组都必须可点击切换；
- 每个分组右侧都必须是可编辑表单；
- 不能只有“基础资料”可编辑，其他分组只作为静态标签。

右侧表单区：

基础资料：

- 账号/品牌名称；
- 目标用户；
- 当前内容问题；
- 希望用户看完后的动作；
- 内容禁区。

品牌资料：

- 品牌定位；
- 主推商品；
- 商品卖点；
- 使用场景；
- 购买渠道；
- 品牌信任来源。

个人 IP 资料：

- 身份标签；
- 专业能力；
- 真实经历；
- 核心观点；
- 产品或服务；
- 人设边界。

素材条件：

- 是否有产品实拍；
- 是否有使用前后对比；
- 是否有截图；
- 是否有人物、宠物或门店出镜；
- 是否有品牌视觉规范；
- 禁止使用的素材；
- 当前最容易补拍或补做的素材。

对标参考：

- 对标账号名；
- 链接或截图；
- 可学习标题结构；
- 可学习内容结构；
- 不建议照搬点。

生成约束：

- 标题不超过 20 字；
- 正文不超过 1000 字；
- 图片生成方式偏好；
- 话题偏好；
- 禁用词；
- 风格偏好。

### 主要按钮

- 保存资料库；
- 保存并生成定位；
- 放弃修改。

### 页面状态

- 必填字段缺失；
- 可保存；
- 已保存；
- 更新后建议重新生成定位和主线。

### 质检提示

资料库缺少以下内容时，内容管理页要提醒：

- 目标用户；
- 当前内容问题；
- 希望用户看完后的动作；
- 内容禁区；
- 品牌主推商品或个人 IP 真实经历；
- 可用素材或素材限制。

资料库保存完成后：

- 项目管理页的项目记录状态更新；
- 内容管理解除不可用状态；
- 可以选择该资料库账号生成笔记。

## 6. 定位与内容主线页

### 页面目标

展示、生成和编辑账号定位与 3 条长期内容主线。

### 页面布局

顶部状态：

- 定位生成状态；
- 资料库来源；
- 最近更新时间；

定位模块：

- 目标用户；
- 核心卖点或专业优势；
- 差异化表达；
- 内容边界；

内容主线模块：

- 主线名称；
- 适合目标用户；
- 解决的问题；
- 适合写法；
- 不适合写法；
- 本主线适合的字数档位和图片生成方式。

### 主要按钮

- 生成定位；
- 重新生成；
- 保存编辑；
- 去生成笔记。

### 页面状态

- 未生成；
- 生成中；
- 已生成；
- 用户已编辑；
- 资料库更新后建议重新生成。

### 跳转

- 去生成笔记 -> 内容管理页。

## 7. 内容管理页

### 页面目标

从资料库选择已保存账号，选择一个内容场景，进入素材输入和诊断流程。

### 页面布局

顶部说明：

- 本页是内容管理入口；
- 先选择场景卡，再进入诊断；
- P0 每次生成 3 篇；
- 后期可扩展为 N 篇；
- 本次会读取资料库、定位、内容主线和反馈建议；
- 图片在单篇笔记详情页生成。

场景卡区：

- 主页诊断；
- 找对标账号；
- 爆文拆解；
- 关键词洞察；
- 草稿改写；
- 发布前体检；
- 7 天发布计划；
- 发布复盘；
- 内容知识库；
- 变现判断。

第一轮验证重点卡：

- 草稿改写；
- 发布前体检；
- 发布复盘。

每张卡展示：

- 场景名称；
- 适合什么时候用；
- 需要提供的素材；
- 预计输出；
- 主按钮：开始诊断。

右侧资料引用预览：

- 当前定位；
- 已选内容主线；
- 可用素材条件；
- 上一次优化建议摘要；
- 生成约束。

底部最近任务：

- 最近一次场景；
- 最近一次诊断摘要；
- 最近生成的 3 篇笔记；
- 待反馈提醒。

### 页面状态

- 资料库为空，内容管理不可用；
- 可选择场景卡；
- 已选择场景卡；
- 有未完成诊断；
- 有最近任务；
- 有待反馈笔记。

### 跳转

- 开始诊断 -> 场景卡素材输入状态；
- 查看最近任务 -> 任务历史页；
- 补资料 -> 资料库页。

## 8. 场景卡素材输入状态

### 页面目标

让用户为本次场景提供最少素材，而不是授权平台或填写复杂表单。

### 页面布局

顶部：

- 已选场景卡；
- 本场景需要的素材说明；
- 本场景会读取的资料库信息。

素材输入：

- 主页链接或截图；
- 对标账号链接或截图；
- 单篇内容链接或截图；
- 草稿正文；
- 关键词；
- 评论区截图；
- 后台数据截图；
- 用户备注。

提示：

- 至少提供一种素材即可启动；
- 链接、截图和后台图只作为用户提供的素材；
- 当前不做平台爬取或自动解析。

## 核心路径线框

### 路径 1：首次使用

登录/注册页 -> 项目列表页 -> 创建项目页 -> 项目首页 -> 资料库页 -> 定位与内容主线页 -> 内容管理页 -> 场景卡素材输入状态 -> 诊断结果状态 -> 笔记详情/编辑页 -> 生成图片

成功标准：

- 用户第一次使用能先看到诊断判断，再拿到 3 篇可编辑、可质检的小红书笔记，并能生成配图或把内容变成图片。

### 路径 2：日常生成

项目列表页 -> 项目首页 -> 内容管理页 -> 场景卡素材输入状态 -> 诊断结果状态 -> 任务历史页 -> 笔记详情/编辑页 -> 按需生成图片

成功标准：

- 用户不用重新填写长期资料，也能基于本次场景和素材再次生成一组笔记。

### 路径 3：反馈优化

任务历史页 -> 发布反馈页 -> 优化建议页 -> 内容管理页 -> 场景卡素材输入状态 -> 诊断结果状态 -> 新一轮 3 篇笔记

成功标准：

- 用户能把发布反馈转成下一轮内容实验，而不是停留在一次性文案。

## 原型验收清单

生成低保真可视化原型时，至少检查：

1. 是否能从登录走到项目创建；
2. 项目大类是否初始化后不可更改；
3. 项目首页是否能告诉用户下一步；
4. 资料库是否能保存长期资料和素材条件；
5. 定位与主线是否可生成、可编辑；
6. 内容管理页是否有场景卡入口；
7. 场景卡是否能进入手动素材输入；
8. 诊断结果是否先于生成 3 篇笔记出现；
9. 内容管理是否突出“生成 3 篇笔记”；
10. 生成前是否只保留正文字数档位选择，不前置选择图片方式；
11. 笔记详情是否显示标题 20 字限制；
12. 笔记详情是否显示正文 1000 字限制；
13. 笔记详情是否有可发布质检；
14. 笔记详情是否能选择生成配图或内容变成图片；
15. 内容变成图片是否有正文精简版和图片页结构；
16. 发布反馈是否能记录高价值评论；
17. 优化建议是否能进入下一轮生成；
18. 品牌和个人 IP 两个样本是否都能跑通；
19. 页面里是否没有销售、涨粉、爆款承诺；
20. 页面里是否没有暗示平台自动抓取或自动解析。
