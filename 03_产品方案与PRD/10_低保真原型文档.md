# 小红书定位与内容验证助手 - 低保真原型文档

更新日期：2026-06-11

当前状态：低保真原型文档 v0.1。

说明：本文用于把 PRD、原型前置说明和 MVP 闭环走查结果，落成可视化原型前的页面草图说明。当前只定义页面结构、字段、状态和跳转，不做高保真视觉、不做代码开发。

## 结论

低保真原型第一版只验证一件事：

**用户能否从登录进入项目，完成资料库，生成定位和内容主线，并拿到 3 篇可发布检查的小红书图文笔记。**

原型形态建议：

- 信息密度适中，像一个内容工作台；
- 不做营销首页；
- 不做复杂仪表盘；
- 不做自动发布、自动抓取、自动成图；
- 重点突出“下一步该做什么”和“这篇笔记能不能发”。

## 设计 Brief

产品目标：

帮助品牌和个人 IP 保存长期资料，并每次生成 3 篇能发的小红书图文笔记。

当前样本：

- 品牌 - 宠物用品；
- 个人 IP - 知识分享。

视觉来源：

- 暂无现成视觉系统；
- 低保真阶段只需要灰度线框、信息层级和交互路径；
- 后续再决定视觉风格。

交互级别：

- 静态低保真；
- 关键按钮、状态和跳转关系要明确；
- 不要求真实表单校验或真实 AI 生成。

## 1. 登录/注册页

### 页面目标

让用户进入自己的工作区，保存项目、资料库、生成历史和反馈。

### 页面布局

上半区：

- 产品名称；
- 一句话说明；
- 登录方式切换。

中间表单：

- 手机号或邮箱；
- 验证码或密码；
- 登录/注册按钮。

底部提示：

- 登录只用于保存项目和生成历史；
- 不需要授权小红书账号。

### 主要按钮

- 登录；
- 注册；
- 获取验证码；
- 忘记密码。

### 页面状态

- 未输入；
- 输入不完整；
- 验证中；
- 登录失败；
- 登录成功。

### 跳转

- 登录成功 -> 项目列表页；
- 已有项目 -> 项目列表页；
- 无项目 -> 项目列表空状态。

## 2. 项目列表页

### 页面目标

让用户查看已有项目，或创建第一个项目。

### 页面布局

顶部：

- 页面标题：我的项目；
- 新建项目按钮。

项目卡片：

- 项目名称；
- 项目大类；
- 细分方向；
- 资料库完成度；
- 最近生成时间；
- 最近反馈状态；
- 进入项目按钮。

空状态：

- 文案：先创建一个小红书内容项目；
- 主按钮：新建项目。

### 筛选/展示

- 全部；
- 品牌；
- 个人 IP。

### 页面状态

- 无项目；
- 有项目但资料未完成；
- 有项目且可生成；
- 项目有待反馈笔记。

### 跳转

- 新建项目 -> 创建项目页；
- 进入项目 -> 项目首页。

## 3. 创建项目页

### 页面目标

初始化项目，并确认不可更改的项目大类。

### 页面布局

步骤 1：项目基础信息

- 项目名称；
- 账号/品牌名称；
- 小红书账号链接或截图。

步骤 2：项目大类

- 品牌；
- 个人 IP。

步骤 3：细分方向

- 品牌：宠物、餐饮、美妆、母婴、本地生活、其他；
- 个人 IP：知识分享、美妆、育儿、职场、情感、其他。

底部确认区：

- 项目大类创建后不可更改；
- 选错大类需要新建项目；
- 细分方向后期可调整，但建议重新生成定位和主线。

### 主要按钮

- 上一步；
- 下一步；
- 创建项目。

### 页面状态

- 未选择项目大类；
- 已选择品牌；
- 已选择个人 IP；
- 未选择细分方向；
- 创建成功；
- 创建失败。

### 跳转

- 创建成功 -> 项目首页；
- 取消 -> 项目列表页。

## 4. 项目首页

### 页面目标

作为项目工作台，告诉用户当前最应该做哪一步。

### 页面布局

顶部项目摘要：

- 项目名称；
- 项目大类；
- 细分方向；
- 当前状态；
- 最近更新时间。

主行动卡片：

- 资料未完成：完善资料库；
- 资料已完成但未生成定位：生成定位；
- 定位和主线已完成：生成 3 篇笔记；
- 有已发布笔记：填写发布反馈；
- 有反馈：查看优化建议。

四个摘要模块：

- 资料库完成度；
- 账号定位摘要；
- 内容主线摘要；
- 最近任务摘要。

### 主要按钮

- 完善资料库；
- 生成定位和主线；
- 生成 3 篇笔记；
- 填写反馈；
- 查看优化建议。

### 页面状态

- 新项目；
- 资料未完成；
- 资料已完成；
- 可生成内容；
- 有任务历史；
- 有反馈建议。

### 跳转

- 完善资料库 -> 资料库页；
- 生成定位和主线 -> 定位与内容主线页；
- 生成 3 篇笔记 -> 内容生产页；
- 填写反馈 -> 发布反馈页；
- 查看优化建议 -> 优化建议页。

## 5. 资料库页

### 页面目标

沉淀长期资料，让后续生成不用反复填写。

### 页面布局

左侧分组导航：

- 基础资料；
- 品牌资料或个人 IP 资料；
- 内容偏好；
- 素材条件；
- 对标参考；
- 生成约束。

右侧表单区：

基础资料：

- 账号/品牌名称；
- 目标用户；
- 当前内容问题；
- 希望用户看完后的动作；
- 内容禁区。

品牌资料：

- 品牌定位；
- 主推商品；
- 商品卖点；
- 使用场景；
- 购买渠道；
- 品牌信任来源。

个人 IP 资料：

- 身份标签；
- 专业能力；
- 真实经历；
- 核心观点；
- 产品或服务；
- 人设边界。

素材条件：

- 是否有产品实拍；
- 是否有使用前后对比；
- 是否有截图；
- 是否有人物、宠物或门店出镜；
- 是否有品牌视觉规范；
- 禁止使用的素材；
- 当前最容易补拍或补做的素材。

对标参考：

- 对标账号名；
- 链接或截图；
- 可学习标题结构；
- 可学习内容结构；
- 不建议照搬点。

生成约束：

- 标题不超过 20 字；
- 正文不超过 1000 字；
- 内容承载方式偏好；
- 话题偏好；
- 禁用词；
- 风格偏好。

### 主要按钮

- 保存资料库；
- 保存并生成定位；
- 放弃修改。

### 页面状态

- 必填字段缺失；
- 可保存；
- 已保存；
- 更新后建议重新生成定位和主线。

### 质检提示

资料库缺少以下内容时，内容生产页要提醒：

- 目标用户；
- 当前内容问题；
- 希望用户看完后的动作；
- 内容禁区；
- 品牌主推商品或个人 IP 真实经历；
- 可用素材或素材限制。

### 主要按钮

### 页面状态

- 生成中；

- 资料库更新后建议重新生成。

## 7. 内容生产页

### 页面目标

创建一次生成任务，P0 固定生成 3 篇图文笔记。

### 页面布局

顶部说明：

- P0 每次生成 3 篇；
- 后期可扩展为 N 篇；
- 本次会读取资料库、定位、内容主线和反馈建议。

左侧任务表单：

- 任务名称；
- 内容目的；
- 选择内容主线；
- 内容承载方式；
- 正文承载型字数档位；
- 图片承载型图片页数建议；
- 笔记风格；
- 本次强调内容；
- 本次避开内容；
- 本次可用素材或素材限制；
- 是否参考上一次优化建议。

右侧资料引用预览：

- 当前定位；
- 已选内容主线；
- 可用素材条件；
- 上一次优化建议摘要；
- 生成约束。

底部生成区：

- 主按钮：生成 3 篇笔记；
- 提示：不自动发布，不自动生成图片。

### 内容承载方式

正文承载型：

- 短正文：200-400 字；
- 标准正文：500-800 字；
- 长正文：800-1000 字。

图片承载型：

- 正文精简版：100-300 字；
- 图片页数建议：3-8 页；
- 每页包含页标题、核心要点、页面文案和视觉建议。

### 页面状态

- 资料库缺关键字段，不能生成；
- 可生成；
- 生成中；
- 生成成功；
- 生成失败；
- 已保存到任务历史。

### 跳转

- 生成成功 -> 任务历史页或笔记详情页；
- 资料缺失 -> 资料库页。

## 9. 笔记详情/编辑页

### 页面目标

让用户编辑单篇可发布的小红书图文笔记，并判断它是否能发。

### 页面布局

左侧编辑区：

- 标题；
- 封面文案；
- 正文；
- 推荐话题；
- 评论引导；
- 发布观察点。

右侧建议区：

- 内容承载方式；
- 正文承载型字数档位；
- 封面图建议；
- 配图建议；
- 图片页结构；
- 可发布质检。

底部操作区：

- 保存草稿；
- 标记已发布；
- 返回任务；
- 填写反馈。

### 标题与正文质检

标题：

- 当前字数；
- 是否超过 20 字；
- 是否有夸大承诺。

正文：

- 当前字数；
- 是否超过 1000 字；
- 是否符合字数档位；
- 是否适合切换为图片承载型。

### 可发布质检

质检项：

- 标题不超过 20 字；
- 正文不超过 1000 字；
- 正文承载型符合字数档位；
- 图片承载型包含正文精简版和图片页结构；
- 有 5-8 个推荐话题；
- 有封面图建议；
- 有 3-6 张配图建议；
- 有发布观察点；
- 无销售、涨粉、爆款承诺；
- 无绝对化表达。

显示方式：

- 通过；
- 需修改；
- 缺失。

### 图片页结构

图片承载型显示：

- 页码；
- 页标题；
- 核心要点；
- 页面文案；
- 视觉建议。

正文承载型显示：

- 普通配图建议；
- 不强制展示图片页结构。

### 页面目标

### 页面布局

- 关联任务；
- 关联笔记；
- 引用的关键数据；
- 引用的高价值评论；
- 上一轮内容主线。

- 下一次生成任务建议；
- 可带入下一次生成任务的参数；
- 标题优化方向；

- 话题调整建议；
- 封面图和配图调整建议；
- 继续测试或暂停的内容方向；
- 建议依据。

底部操作区：

- 基于建议新建生成任务；

### 页面状态

- 反馈不足，不能生成；
- 生成中；
- 已生成；

- 必须说明依据；
- 必须连接到内容主线；
- 必须能转成下一次生成任务。

## 核心路径线框

### 路径 1：首次使用

登录/注册页 -> 项目列表页 -> 创建项目页 -> 项目首页 -> 资料库页 -> 定位与内容主线页 -> 内容生产页 -> 笔记详情/编辑页

成功标准：

- 用户第一次使用能拿到 3 篇可编辑、可质检的小红书图文笔记。

### 路径 2：日常生成

项目列表页 -> 项目首页 -> 内容生产页 -> 任务历史页 -> 笔记详情/编辑页

成功标准：

- 用户不用重新填写长期资料，也能再次生成一组笔记。

### 路径 3：反馈优化

任务历史页 -> 发布反馈页 -> 优化建议页 -> 内容生产页 -> 新一轮 3 篇笔记

成功标准：

- 用户能把发布反馈转成下一轮生成任务，而不是停留在一次性文案。

## 原型验收清单

生成低保真可视化原型时，至少检查：

1. 是否能从登录走到项目创建；
2. 项目大类是否初始化后不可更改；
3. 项目首页是否能告诉用户下一步；
4. 资料库是否能保存长期资料和素材条件；
5. 定位与主线是否可生成、可编辑；
6. 内容生产页是否突出“生成 3 篇笔记”；
7. 内容生产页是否能选择正文承载型或图片承载型；
8. 笔记详情是否显示标题 20 字限制；
9. 笔记详情是否显示正文 1000 字限制；
10. 笔记详情是否有可发布质检；
11. 图片承载型是否有图片页结构；
12. 发布反馈是否能记录高价值评论；
13. 优化建议是否能进入下一轮生成；
14. 品牌和个人 IP 两个样本是否都能跑通；
15. 页面里是否没有销售、涨粉、爆款承诺。
