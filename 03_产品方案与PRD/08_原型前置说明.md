# 小红书定位与内容验证助手 - 原型前置说明

更新日期：2026-06-11

当前状态：原型前置文档。

说明：本文用于生成原型前确认页面范围、字段、用户路径、状态流转和模拟样本。当前仍不进入视觉设计、低保真线框、高保真原型或开发。

## 结论

生成原型前，先把 MVP v0.2 的 5 个产品区域落成页面和字段。

原型目标不是展示完整系统，而是验证：

**用户登录后，能创建项目、沉淀资料库、每次生成 3 篇能发的小红书图文笔记，并用反馈驱动下一轮生成。**

## 原型范围

### 必须覆盖

1. 登录；
2. 项目管理；
3. 资料库；
4. 内容生产区；
5. 数据反馈。

### 暂不覆盖

- 会员；
- 支付；
- 团队协作；
- 小红书授权；
- 自动发布；
- 自动抓取数据；
- 自动生成图片；
- 自动排版成图；
- CRM；
- 后台管理系统。

## 页面清单

P0 原型建议包含 11 个页面：

1. 登录/注册页；
2. 项目列表页；
3. 创建项目页；
4. 项目首页；
5. 资料库页；
6. 定位与内容主线页；
7. 内容生产页；
8. 任务历史页；
9. 笔记详情/编辑页；
10. 发布反馈页；
11. 优化建议页。

## 页面字段清单

### 1. 登录/注册页

页面目标：

让用户进入自己的工作区。

核心字段：

- 手机号或邮箱；
- 验证码或密码；
- 登录按钮；
- 注册入口；
- 退出登录状态提示。

关键状态：

- 未输入；
- 输入不完整；
- 验证中；
- 登录失败；
- 登录成功。

原型重点：

- 不出现小红书授权；
- 不出现会员套餐；
- 登录只是为了保存项目、资料库、生成历史和反馈。

### 2. 项目列表页

页面目标：

让用户选择已有项目，或新建项目。

核心字段：

- 项目名称；
- 项目类型；
- 最近生成时间；
- 资料库状态；
- 最近任务状态；
- 新建项目按钮。

项目类型：

- 宠物品牌；
- 个人 IP。

关键状态：

- 无项目；
- 有项目但资料未完成；
- 有项目且可生成；
- 项目已有历史任务。

原型重点：

- 项目类型要明显展示；
- 从这里能进入项目首页；
- 空状态要引导创建第一个项目。

### 3. 创建项目页

页面目标：

初始化项目，并确定不可更改的项目类型。

核心字段：

- 项目名称；
- 项目类型；
- 账号/品牌名称；
- 小红书账号链接或截图；
- 创建按钮。

项目类型选择：

- 宠物品牌：适合有品牌和商品的人；
- 个人 IP：适合有专业能力、经历、观点或服务的人。

关键提示：

项目类型创建后不可更改。选错类型需要新建项目。

关键状态：

- 未选择类型；
- 已选择宠物品牌；
- 已选择个人 IP；
- 创建成功；
- 创建失败。

原型重点：

- 项目类型选择必须足够明确；
- 不要让用户误以为后面可以随便切换类型。

### 4. 项目首页

页面目标：

给用户一个项目工作台入口。

核心模块：

- 项目摘要；
- 资料库完成度；
- 账号定位摘要；
- 内容主线摘要；
- 最近生成任务；
- 最近发布反馈；
- 下一步建议。

主要操作：

- 去完善资料库；
- 查看定位与内容主线；
- 新建生成任务；
- 查看任务历史；
- 填写发布反馈。

关键状态：

- 资料未完成：主按钮为“完善资料库”；
- 资料已完成但未生成定位：主按钮为“生成定位”；
- 定位和主线已完成：主按钮为“生成 3 篇笔记”；
- 有发布反馈：显示“查看优化建议”。

原型重点：

- 项目首页不做复杂仪表盘；
- 只告诉用户下一步该做什么。

### 5. 资料库页

页面目标：

沉淀长期资料，让后续每次生成不用重新填写。

共同字段：

- 账号/品牌名称；
- 小红书账号链接或截图；
- 目标用户；
- 当前内容问题；
- 希望用户看完后的动作；
- 内容禁区；
- 可用素材；
- 对标账号；
- 话题偏好；
- 禁用词；
- 风格偏好。

宠物品牌字段：

- 品牌定位；
- 主推商品；
- 商品卖点；
- 适用宠物；
- 使用场景；
- 购买渠道；
- 品牌信任来源。

个人 IP 字段：

- 身份标签；
- 专业能力；
- 真实经历；
- 核心观点；
- 产品或服务；
- 人设边界；
- 可信任素材。

关键状态：

- 必填字段缺失；
- 可保存；
- 已保存；
- 已更新，需要重新生成定位或内容主线。

原型重点：

- 表单要分组，不要一屏堆满；
- 必填字段要少；
- 资料库要体现“长期资产”，不是一次性问卷。

### 6. 定位与内容主线页

页面目标：

展示并编辑账号定位和 3 条长期内容主线。

定位字段：

- 账号一句话定位；
- 目标用户；
- 核心卖点或专业优势；
- 差异化表达；
- 内容边界；
- 不建议做的方向。

内容主线字段：

- 主线名称；
- 适合目标用户；
- 解决的问题；
- 适合写法；
- 不适合写法。

默认主线：

- 宠物品牌：场景种草、问题解决、品牌信任；
- 个人 IP：经历故事、专业判断、方法拆解。

关键状态：

- 未生成；
- 生成中；
- 已生成；
- 用户已编辑；
- 资料库更新后建议重新生成。

原型重点：

- 定位和内容主线要可编辑；
- 后续生成任务默认读取最新版定位和主线。

### 7. 内容生产页

页面目标：

让用户新建一次生成任务，每次产出 3 篇图文笔记。

任务输入字段：

- 本次内容目的；
- 选择内容主线；
- 正文字数档位；
- 笔记风格；
- 本次想强调的商品、经历或观点；
- 本次想避开的内容；
- 是否参考上一次优化建议。

内容目的：

- 建立认知；
- 解决疑问；
- 建立信任；
- 激发收藏；
- 引导评论；
- 引导私信；
- 商品种草；
- 关注互动。

正文字数档位：

- 短笔记：300-500 字；
- 标准笔记：600-900 字；
- 长笔记：1000-1500 字。

生成结果：

- 固定 3 篇图文笔记；
- 每篇展示标题、内容目的、主线、状态和编辑入口。

关键状态：

- 资料库缺关键字段，不能生成；
- 可生成；
- 生成中；
- 生成成功；
- 生成失败；
- 已保存到任务历史。

原型重点：

- “生成 3 篇笔记”是此页主按钮；
- 生成前要显示调用了哪些资料库信息；
- 不做批量生成，不做短视频脚本。

### 8. 任务历史页

页面目标：

保存每次生成的 3 篇笔记，支持用户反复使用。

核心字段：

- 任务名称；
- 创建时间；
- 内容目的；
- 选择的内容主线；
- 3 篇笔记标题；
- 发布状态；
- 反馈状态；
- 优化建议状态。

任务状态：

- 已生成；
- 部分已发布；
- 已反馈；
- 已优化；
- 已归档。

主要操作：

- 打开任务；
- 编辑笔记；
- 标记已发布；
- 填写反馈；
- 查看优化建议。

原型重点：

- 历史任务要体现“每次 3 篇”；
- 用户重新登录后能继续编辑和反馈。

### 9. 笔记详情/编辑页

页面目标：

让用户编辑单篇可发布的小红书图文笔记。

字段：

- 标题；
- 是否超过 20 字；
- 封面文案；
- 封面图建议；
- 正文；
- 正文字数档位；
- 当前字数；
- 配图建议；
- 推荐话题；
- 评论引导；
- 发布观察点。

配图建议字段：

- 图片序号；
- 图片内容；
- 素材类型；
- 拍摄/制作建议；
- 作用。

推荐话题字段：

- 话题；
- 类型；
- 推荐理由。

笔记状态：

- 草稿；
- 已编辑；
- 已发布；
- 已反馈；
- 已归档。

原型重点：

- 标题 20 字限制要显性提示；
- 正文字数要显示当前字数；
- 封面图和配图只是建议，不自动生成图片；
- 每篇笔记都要有发布观察点。

### 10. 发布反馈页

页面目标：

用户手动记录发布后的基础反馈。

字段：

- 关联笔记；
- 发布时间；
- 浏览；
- 点赞；
- 收藏；
- 评论；
- 私信；
- 关注变化；
- 商品咨询或购买意向；
- 用户主观反馈；
- 截图或备注。

宠物品牌重点字段：

- 商品咨询；
- 购买意向；
- 私信；
- 收藏。

个人 IP 重点字段：

- 关注变化；
- 评论质量；
- 私信；
- 用户是否记住账号定位。

关键状态：

- 未填写；
- 部分填写；
- 已保存；
- 可生成优化建议。

原型重点：

- 不要求用户填满所有数据；
- 至少有主观反馈或核心数据，才允许生成优化建议。

### 11. 优化建议页

页面目标：

根据发布反馈，给下一轮生成任务提供方向。

输出字段：

- 下一轮内容方向；
- 下一次生成任务建议；
- 标题优化方向；
- 正文角度调整；
- 话题调整建议；
- 封面图和配图调整建议；
- 继续测试或暂停的内容方向；
- 建议依据。

主要操作：

- 复制建议；
- 基于建议新建生成任务；
- 返回任务历史；
- 查看关联反馈。

关键状态：

- 反馈不足，不能生成；
- 生成中；
- 已生成；
- 已被下一次任务引用。

原型重点：

- 优化建议必须说明依据；
- 不只看点赞；
- 要能连接到下一次生成任务。

## 核心用户路径

### 路径 1：首次使用

1. 用户注册/登录；
2. 进入项目列表；
3. 点击新建项目；
4. 选择项目类型；
5. 填写项目基础信息；
6. 进入资料库；
7. 完善关键资料；
8. 生成账号定位；
9. 生成 3 条内容主线；
10. 新建生成任务；
11. 生成 3 篇图文笔记；
12. 进入笔记详情页编辑。

成功标准：

- 用户能在第一次使用中拿到 3 篇可修改发布的图文笔记。

### 路径 2：日常生成

1. 用户登录；
2. 进入已有项目；
3. 查看资料库和上次任务；
4. 进入内容生产页；
5. 选择内容目的和内容主线；
6. 设置字数档位和风格；
7. 点击生成 3 篇笔记；
8. 保存到任务历史；
9. 编辑单篇笔记。

成功标准：

- 用户不需要重新填写长期资料，也能再次生成 3 篇笔记。

### 路径 3：反馈优化

1. 用户打开任务历史；
2. 选择已发布笔记；
3. 填写发布反馈；
4. 保存反馈；
5. 生成优化建议；
6. 查看下一轮方向；
7. 基于建议新建生成任务；
8. 再生成 3 篇笔记。

成功标准：

- 用户能从发布数据和主观反馈进入下一轮生成，而不是停留在一次性文案。

- 或用户主观反馈；
- 或截图/备注。

## 模拟样本

### 样本 A：宠物品牌

项目类型：宠物品牌。

项目名称：爪爪净饮小红书项目。

账号/品牌名称：爪爪净饮。

品牌定位：

给城市养猫家庭做低噪音、好清洗的宠物饮水用品。

目标用户：

25-35 岁城市养猫人，尤其是新手猫主人、多猫家庭、担心猫咪喝水少的人。

主推商品：

低噪音宠物饮水机。

商品卖点：

- 运行声音低，适合卧室和小户型；
- 水路结构简单，清洗不费劲；
- 流动水设计，帮助猫咪更愿意喝水。

使用场景：

- 猫咪不爱喝水；
- 主人白天上班，担心饮水不够；
- 旧饮水机声音大，影响睡眠；
- 饮水机清洗麻烦，容易闲置。

内容禁区：

- 不承诺治疗泌尿问题；
- 不夸大“用了就一定多喝水”；
- 不攻击竞品。

内容主线：

1. 场景种草：小户型养猫怎么选安静饮水机；
2. 问题解决：猫咪喝水少，主人可以先观察什么；
3. 品牌信任：为什么好清洗比花哨功能更重要。

生成任务示例：

- 内容目的：商品种草；
- 内容主线：场景种草；
- 正文字数档位：标准笔记；
- 本次强调：低噪音、好清洗、小户型养猫。

3 篇笔记标题示例：

1. 猫咪喝水少先看这点；
2. 小户型饮水机别买吵的；
3. 饮水机闲置多半因为难洗。

反馈示例：

- 收藏较高；
- 评论集中问清洗频率；
- 有 2 个用户私信问购买渠道。

优化建议示例：

下一轮强化“好清洗”和“多猫家庭使用场景”，减少泛泛讲参数，多展示清洗步骤和真实摆放位置。

### 样本 B：个人 IP

项目类型：个人 IP。

项目名称：林夕的内容运营笔记。

账号/品牌名称：林夕做内容。

定位：

一个帮小团队把产品卖点变成小红书内容的人。

目标用户：

有产品或服务，但不知道怎么在小红书表达的一人公司、小工作室和个人 IP。

专业能力：

- 小红书账号定位；
- 产品卖点拆解；
- 图文笔记策划；
- 内容复盘。

真实经历：

曾经帮一个本地摄影工作室把“拍得好看”拆成孕妈照、证件照、亲子照三个场景内容线，第一轮测试后评论更具体。

核心观点：

- 内容不是想到什么发什么；
- 对标账号不能直接抄，要拆结构；
- 小红书笔记要同时解决选题、封面、正文和反馈。

内容禁区：

- 不承诺 7 天涨粉；
- 不承诺爆款；
- 不讲虚假成交案例。

内容主线：

1. 经历故事：我怎么帮小团队拆内容方向；
2. 专业判断：什么样的选题不适合新号；
3. 方法拆解：一篇小红书笔记怎么从卖点开始写。

- 内容目的：建立信任；
- 内容主线：方法拆解；
- 正文字数档位：长笔记；
- 本次强调：小红书笔记不是只写正文，还要有封面、配图和反馈。

反馈示例：

- 收藏高于点赞；
- 私信里有 1 个潜在咨询。

优化建议示例：

下一轮继续做“卖点到笔记”的拆解，但标题更具体，封面增加对比句，让用户一眼看出适合谁。

## 原型验收标准

生成原型后，至少要检查：

1. 是否能从登录走到项目创建；
2. 项目类型是否初始化后不可更改；
3. 资料库是否能表达长期资产；
4. 内容生产区是否突出“每次生成 3 篇”；
5. 任务历史是否能承接反复使用；
6. 笔记详情是否包含标题、封面、正文、话题、配图和观察点；
7. 发布反馈是否支持手动填写；
8. 优化建议是否能引导下一轮生成；
9. 宠物品牌和个人 IP 两个样本是否都能跑通；
10. 页面里是否没有销售、涨粉、爆款承诺。

## 下一步

1. 先确认本文中的页面、字段、路径和状态是否完整；
2. 如确认进入原型阶段，再基于本文生成低保真原型；
3. 用两个模拟样本检查原型流程，再决定是否进入视觉设计或开发。
