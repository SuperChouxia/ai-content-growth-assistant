# AI 创作工具 / 内容增长工作台 - 原型前置说明

更新日期：2026-07-01

文档版本：MVP v0.5

当前状态：历史原型前置文档，仅保留旧版字段与路径参考。

说明：本文用于生成或更新原型前确认页面范围、字段、用户路径、状态流转和模拟样本。当前仍不进入正式开发。

当前口径提示（2026-08-07）：本文正文记录 MVP v0.5 的历史方案，不再作为当前需求。MVP v0.8 已统一为“左侧一级菜单 + 中间上下文列表 + 右侧工作区”，一级模块为对话、创作、账号；个人中心隐藏中栏并使用整块右侧区域；创作结果只读，创作历史按账号展示笔记，单篇详情只保留 1-6 张生成配图。当前以 `07_PRD_MVP.md`、`11_MVP产品设计方案.md`、`../04_可视化原型/00_原型版本.md` 和 `../05_技术方案/12_MVP技术方案.md` 为准。

## 结论

生成原型前，先把 MVP v0.5 的 3 个主菜单和内容管理场景卡路径落成页面和字段。

原型目标不是展示完整系统，而是验证：

**用户登录后，能创建项目、沉淀资料库，在内容管理选择场景卡并手动提供素材，先看到诊断判断，再生成 3 篇能发的小红书笔记，并可对单篇笔记生成配图或把内容变成图片。**

说明：

- P0 每次固定生成 3 篇；
- 后期可扩展为 N 篇；
- 场景卡先诊断，再生成；
- P0 不做平台爬取或自动解析；
- 笔记生成前只选择正文字数档位；
- 笔记生成后再选择图片生成方式：生成配图或内容变成图片。

## 原型范围

### 必须覆盖

1. 登录；
2. 项目管理；
3. 内容管理；
4. 数据反馈。

### 暂不覆盖

- 会员；
- 支付；
- 团队协作；
- 小红书授权；
- 自动发布；
- 自动抓取数据；
- 自动解析平台数据；
- 大规模对标账号库；
- 完整素材库自动采集；
- 开放式文生图；
- 复杂图片编辑器；
- 自动生成真实商品图；
- 自动排版成可自由编辑设计稿；
- CRM；
- 后台管理系统。

## 页面清单

P0 原型建议包含 13 个页面或内部状态：

1. 登录/注册页；
2. 项目列表页；
3. 创建项目页；
4. 项目首页；
5. 资料库页；
6. 定位与内容主线页；
7. 内容管理页；
8. 场景卡素材输入状态；
9. 诊断结果状态；
10. 任务历史页；
11. 笔记详情/编辑页；
12. 发布反馈页；
13. 优化建议页。

说明：

- 场景卡、素材输入和诊断结果可以先做成内容管理页内状态；
- 不新增左侧一级菜单；
- 不破坏“选择字数 -> 生成 3 篇笔记 -> 单篇详情生成图片”的主闭环。

## 页面字段清单

### 1. 登录/注册页

页面目标：

让用户进入自己的工作区。

核心字段：

- 手机号或邮箱；
- 验证码或密码；
- 登录按钮；
- 注册入口；
- 退出登录状态提示。

关键状态：

- 未输入；
- 输入不完整；
- 验证中；
- 登录失败；
- 登录成功。

原型重点：

- 不出现小红书授权；
- 不出现会员套餐；
- 登录只是为了保存项目、资料库、生成历史和反馈。

### 2. 项目列表页

页面目标：

让用户选择已有项目，或新建项目。

核心字段：

- 项目名称；
- 项目大类；
- 细分方向；
- 最近生成时间；
- 资料库状态；
- 最近任务状态；
- 新建项目按钮。

项目大类：

- 品牌；
- 个人 IP。

细分方向：

- 品牌：P0 为宠物，后期可扩展餐饮、美妆、母婴、本地生活、其他；
- 个人 IP：P0 为知识分享，后期可扩展美妆、育儿、职场、情感、其他。

关键状态：

- 无项目；
- 有项目但资料未完成；
- 有项目且可生成；
- 项目已有历史任务。

原型重点：

- 项目大类和细分方向要明显展示；
- 从这里能进入项目首页；
- 空状态要引导创建第一个项目。

### 3. 创建项目页

页面目标：

初始化项目，并确定不可更改的项目大类。

核心字段：

- 项目名称；
- 项目大类；
- 细分方向；
- 账号/品牌名称；
- 小红书账号链接或截图；
- 创建按钮。

项目大类选择：

- 品牌：适合有品牌、商品、门店或产品的人；
- 个人 IP：适合有专业能力、经历、观点或服务的人。

细分方向选择：

- 品牌：宠物、餐饮、美妆、母婴、本地生活、其他；
- 个人 IP：知识分享、美妆、育儿、职场、情感、其他。

关键提示：

项目大类创建后不可更改。选错大类需要新建项目。细分方向后期可调整，但调整后建议重新生成定位和内容主线。

关键状态：

- 未选择类型；
- 已选择品牌；
- 已选择个人 IP；
- 已选择细分方向；
- 创建成功；
- 创建失败。

原型重点：

- 项目大类选择必须足够明确；
- 不要让用户误以为后面可以随便切换大类。

### 4. 项目首页

页面目标：

给用户一个项目工作台入口。

核心模块：

- 项目摘要；
- 资料库完成度；
- 账号定位摘要；
- 内容主线摘要；
- 最近生成任务；
- 最近发布反馈；
- 下一步建议。

主要操作：

- 去完善资料库；
- 查看定位与内容主线；
- 新建生成任务；
- 查看任务历史；
- 填写发布反馈。

关键状态：

- 资料未完成：主按钮为“完善资料库”；
- 资料已完成但未生成定位：主按钮为“生成定位”；
- 定位和主线已完成：主按钮为“进入内容管理”；
- 有发布反馈：显示“查看优化建议”。

原型重点：

- 项目首页不做复杂仪表盘；
- 只告诉用户下一步该做什么。

### 5. 资料库页

页面目标：

沉淀长期资料，让后续每次生成不用重新填写。

共同字段：

- 账号/品牌名称；
- 小红书账号链接或截图；
- 目标用户；
- 当前内容问题；
- 希望用户看完后的动作；
- 内容禁区；
- 可用素材；
- 素材条件；
- 对标账号；
- 话题偏好；
- 禁用词；
- 风格偏好。

素材条件字段：

- 是否有产品实拍；
- 是否有使用前后对比；
- 是否有截图；
- 是否有人物、宠物或门店出镜；
- 是否有品牌视觉规范；
- 禁止使用的素材；
- 当前最容易补拍或补做的素材。

品牌字段：

- 细分方向；
- 品牌定位；
- 主推商品；
- 商品卖点；
- 适用品类或消费场景；
- 使用场景；
- 购买渠道；
- 品牌信任来源。

个人 IP 字段：

- IP 细分方向；
- 身份标签；
- 专业能力；
- 真实经历；
- 核心观点；
- 产品或服务；
- 人设边界；
- 可信任素材。

关键状态：

- 必填字段缺失；
- 可保存；
- 已保存；
- 已更新，需要重新生成定位或内容主线。

原型重点：

- 表单要分组，不要一屏堆满；
- 必填字段要少；
- 资料库要体现“长期资产”，不是一次性问卷。

### 6. 定位与内容主线页

页面目标：

展示并编辑账号定位和 3 条长期内容主线。

定位字段：

- 账号一句话定位；
- 目标用户；
- 核心卖点或专业优势；
- 差异化表达；
- 内容边界；
- 不建议做的方向。

内容主线字段：

- 主线名称；
- 适合目标用户；
- 解决的问题；
- 适合写法；
- 不适合写法。

默认主线：

- 品牌：场景种草、问题解决、品牌信任；
- 个人 IP：经历故事、专业判断、方法拆解。

关键状态：

- 未生成；
- 生成中；
- 已生成；
- 用户已编辑；
- 资料库更新后建议重新生成。

原型重点：

- 定位和内容主线要可编辑；
- 后续生成任务默认读取最新版定位和主线。

### 7. 内容管理页

页面目标：

让用户从场景卡进入本次内容任务，先完成诊断，再生成 3 篇小红书笔记。

说明：

- P0 固定生成 3 篇；
- 后期可扩展为 N 篇；
- 场景卡先诊断，再生成；
- P0 素材由用户手动输入；
- 生成笔记前只选择正文字数档位；
- 生成图片是笔记详情页里的二次动作。

顶部场景卡：

- 主页诊断；
- 找对标账号；
- 爆文拆解；
- 关键词洞察；
- 草稿改写；
- 发布前体检；
- 7 天发布计划；
- 发布复盘；
- 内容知识库；
- 变现判断。

第一轮验证重点：

- 草稿改写；
- 发布前体检；
- 发布复盘。

场景卡字段：

- 场景名称；
- 适合什么时候用；
- 需要提供的素材；
- 预计输出；
- 主按钮：开始诊断。

### 8. 场景卡素材输入状态

页面目标：

让用户为本次场景提供最少素材，而不是授权平台或填写复杂表单。

可输入素材：

- 主页链接或截图；
- 对标账号链接或截图；
- 单篇内容链接或截图；
- 草稿正文；
- 关键词；
- 评论区截图；
- 后台数据截图；
- 用户备注。

关键提示：

- 至少提供一种素材即可启动；
- 链接、截图和后台图只作为用户提供的素材；
- 当前不做平台爬取或自动解析。

主要按钮：

- 生成诊断；
- 返回场景卡。

关键状态：

- 未选择场景；
- 素材为空；
- 可诊断；
- 诊断中；
- 诊断失败。

### 9. 诊断结果状态

页面目标：

在生成笔记之前，让用户先看到 AI 的判断和本次建议方向。

诊断输出：

- 当前判断；
- 可用素材摘要；
- 风险提醒；
- 建议生成方向；
- 下一步动作；
- 发布后复盘指标。

主要按钮：

- 采用诊断并生成 3 篇笔记；
- 返回补充素材；
- 保存诊断。

关键状态：

- 诊断生成中；
- 诊断成功；
- 诊断结果不足，需要补充素材；
- 已采用诊断进入生成任务。

任务输入字段：

- 已选场景卡；
- 诊断结果摘要；
- 本次内容目的；
- 选择内容主线；
- 生成数量；
- 正文字数档位；
- 笔记风格；
- 本次想强调的商品、经历或观点；
- 本次想避开的内容；
- 本次可用素材或素材限制；
- 是否参考上一次优化建议。

内容目的：

- 建立认知；
- 解决疑问；
- 建立信任；
- 激发收藏；
- 引导评论；
- 引导私信；
- 商品种草；
- 关注互动。

生成数量：

- P0 默认 3 篇，不开放自定义；
- 后期扩展为 N 篇。

正文字数档位：

- 短正文：200-400 字；
- 标准正文：500-700 字；
- 长正文：800-1000 字。

生成图片说明：

- 内容管理页不前置选择图片方式；
- 进入单篇笔记详情后再选择生成图片；
- 图片生成方式为生成配图或内容变成图片。

生成结果：

- P0 固定 3 篇笔记；
- 每篇展示标题、内容目的、主线、状态和编辑入口。
- 每篇展示对应诊断依据和发布后优先观察指标。

关键状态：

- 资料库缺关键字段，不能生成；
- 可生成；
- 生成中；
- 生成成功；
- 生成失败；
- 已保存到任务历史。

原型重点：

- “生成 3 篇笔记”是 P0 主按钮；
- 生成前要显示调用了哪些资料库信息；
- 生成前要显示本次可用素材或素材限制；
- 不做批量生成，不做短视频脚本；
- 不在这里直接生成图片。

### 10. 任务历史页

页面目标：

保存每次生成的一组笔记，支持用户反复使用。

核心字段：

- 任务名称；
- 创建时间；
- 场景卡；
- 诊断结果摘要；
- 内容目的；
- 选择的内容主线；
- 生成数量；
- 正文字数档位；
- 笔记标题；
- 图片生成状态；
- 发布状态；
- 反馈状态；
- 优化建议状态。

任务状态：

- 已生成；
- 部分已发布；
- 已反馈；
- 已优化；
- 已归档。

主要操作：

- 打开任务；
- 编辑笔记；
- 生成图片；
- 标记已发布；
- 填写反馈；
- 查看优化建议。

原型重点：

- 历史任务要体现“P0 每次 3 篇，后期可扩展 N 篇”；
- 用户重新登录后能继续编辑和反馈。

### 11. 笔记详情/编辑页

页面目标：

让用户编辑单篇可发布的小红书笔记，并选择是否生成图片。

字段：

- 标题；
- 是否超过 20 字；
- 正文；
- 正文字数档位；
- 当前字数；
- 推荐话题；
- 评论引导；
- 发布观察点。
- 诊断依据；
- 本篇优先复盘指标。
- 可发布质检。

图片生成入口：

- 生成配图；
- 内容变成图片。

生成配图字段：

- 封面图；
- 3-6 张配图；
- 图片用途；
- 画面主体；
- 生成提示；
- 导出状态。

内容变成图片字段：

- 封面图；
- 正文精简版；
- 图片页结构；
- 每页标题；
- 每页核心要点；
- 每页页面文案；
- 每页视觉建议；
- 导出状态。

图片生成规则：

- 优先使用资料库里的已有素材；
- 如果素材不足，要提示需要补拍或补做什么；
- 品牌项目不凭空生成虚假的商品图；
- 图片生成结果不自动替换原始正文。

推荐话题字段：

- 话题；
- 类型；
- 推荐理由。

可发布质检字段：

- 标题是否超过 20 字；
- 正文是否超过 1000 字；
- 正文是否符合字数档位；
- 是否包含热门话题；
- 是否出现销售、涨粉、爆款或绝对化承诺。

笔记状态：

- 草稿；
- 已编辑；
- 已发布；
- 已反馈；
- 已归档。

原型重点：

- 标题 20 字限制要显性提示；
- 正文最多 1000 字，且要显示当前字数；
- 图片生成要作为笔记生成后的二次动作；
- 内容变成图片时要显示图片页结构；
- 每篇笔记要显示可发布质检结果；
- 生成图片可以保存和导出；
- 每篇笔记都要有发布观察点。

### 12. 发布反馈页

页面目标：

用户手动记录发布后的基础反馈。

字段：

- 关联笔记；
- 发布时间；
- 浏览；
- 点赞；
- 收藏；
- 评论；
- 主页访问；
- 私信；
- 关注变化；
- 商品咨询或购买意向；
- 高价值评论；
- 用户主观反馈；
- 截图或备注。

品牌项目重点字段：

- 商品咨询；
- 购买意向；
- 私信；
- 收藏。

个人 IP 重点字段：

- 关注变化；
- 评论质量；
- 私信；
- 用户是否记住账号定位。

关键状态：

- 未填写；
- 部分填写；
- 已保存；
- 可生成优化建议。

原型重点：

- 不要求用户填满所有数据；
- 高价值评论和关键私信要能单独记录；
- 至少有主观反馈或核心数据，才允许生成优化建议。

### 13. 优化建议页

页面目标：

根据发布反馈，给下一轮生成任务提供方向。

输出字段：

- 下一轮内容方向；
- 下一次生成任务建议；
- 可带入下一次生成任务的参数；
- 标题优化方向；
- 正文角度调整；
- 话题调整建议；
- 封面图和配图调整建议；
- 继续测试或暂停的内容方向；
- 建议依据。

主要操作：

- 复制建议；
- 基于建议新建生成任务；
- 返回任务历史；
- 查看关联反馈。

关键状态：

- 反馈不足，不能生成；
- 生成中；
- 已生成；
- 已被下一次任务引用。

原型重点：

- 优化建议必须说明依据；
- 不只看点赞；
- 要引用关键数据或高价值评论；
- 要能连接到下一次生成任务。

## 核心用户路径

### 路径 1：首次使用

1. 用户注册/登录；
2. 进入项目列表；
3. 点击新建项目；
4. 选择项目大类和细分方向；
5. 填写项目基础信息；
6. 进入资料库；
7. 完善关键资料；
8. 生成账号定位；
9. 生成 3 条内容主线；
10. 进入内容管理；
11. 选择场景卡；
12. 手动输入素材；
13. 查看诊断结果；
14. 选择正文字数档位；
15. P0 生成 3 篇笔记；
16. 进入笔记详情页编辑；
17. 选择生成配图或内容变成图片。

成功标准：

- 用户能在第一次使用中先看到诊断判断，再拿到 P0 默认 3 篇可修改发布的笔记，并能继续生成图片。

### 路径 2：日常生成

1. 用户登录；
2. 进入已有项目；
3. 查看资料库和上次任务；
4. 进入内容管理页；
5. 选择场景卡；
6. 输入本次素材；
7. 查看诊断结果；
8. 选择内容目的、内容主线和字数档位；
9. 点击生成 3 篇笔记；
10. 保存到任务历史；
11. 编辑单篇笔记；
12. 按需生成图片。

成功标准：

- 用户不需要重新填写长期资料，也能基于本次场景和素材再次生成一组笔记。

### 路径 3：反馈优化

1. 用户打开任务历史；
2. 选择已发布笔记；
3. 填写发布反馈；
4. 保存反馈；
5. 生成优化建议；
6. 查看下一轮方向；
7. 基于建议进入对应场景卡；
8. 再生成一组笔记。

成功标准：

- 用户能从发布数据和主观反馈进入下一轮生成，而不是停留在一次性文案。

## 模拟样本

### 样本 A：品牌 - 宠物

项目大类：品牌。

细分方向：宠物。

项目名称：爪爪净饮小红书项目。

账号/品牌名称：爪爪净饮。

品牌定位：

给城市养猫家庭做低噪音、好清洗的宠物饮水用品。

目标用户：

25-35 岁城市养猫人，尤其是新手猫主人、多猫家庭、担心猫咪喝水少的人。

主推商品：

低噪音宠物饮水机。

商品卖点：

- 运行声音低，适合卧室和小户型；
- 水路结构简单，清洗不费劲；
- 流动水设计，帮助猫咪更愿意喝水。

使用场景：

- 猫咪不爱喝水；
- 主人白天上班，担心饮水不够；
- 旧饮水机声音大，影响睡眠；
- 饮水机清洗麻烦，容易闲置。

内容禁区：

- 不承诺治疗泌尿问题；
- 不夸大“用了就一定多喝水”；
- 不攻击竞品。

内容主线：

1. 场景种草：小户型养猫怎么选安静饮水机；
2. 问题解决：猫咪喝水少，主人可以先观察什么；
3. 品牌信任：为什么好清洗比花哨功能更重要。

生成任务示例：

- 内容目的：商品种草；
- 内容主线：场景种草；
- 正文字数档位：标准正文 500-700 字；
- 本次强调：低噪音、好清洗、小户型养猫。

生成图片示例：

- 图片生成方式：内容变成图片；
- 正文精简版：100-300 字；
- 图片页数建议：5 页；
- 使用素材：产品实拍、清洗步骤图、小户型摆放图。

3 篇笔记标题示例：

1. 猫咪喝水少先看这点；
2. 小户型饮水机别买吵的；
3. 饮水机闲置多半因为难洗。

反馈示例：

- 收藏较高；
- 评论集中问清洗频率；
- 有 2 个用户私信问购买渠道。

优化建议示例：

下一轮强化“好清洗”和“多猫家庭使用场景”，减少泛泛讲参数，多展示清洗步骤和真实摆放位置。

内容变成图片页面结构示例：

1. 封面：小户型饮水机别买吵的；
2. 场景：卧室、客厅、夜里运行时的噪音困扰；
3. 痛点：猫咪喝水少，主人不在家时更担心；
4. 卖点：低噪音、好清洗、流动水；
5. 结尾：适合哪些养猫家庭，观察猫咪喝水变化。

### 样本 B：个人 IP - 知识分享

项目大类：个人 IP。

细分方向：知识分享。

项目名称：林夕的内容运营笔记。

账号/品牌名称：林夕做内容。

定位：

一个帮小团队把产品卖点变成小红书内容的人。

目标用户：

有产品或服务，但不知道怎么在小红书表达的一人公司、小工作室和个人 IP。

专业能力：

- 小红书账号定位；
- 产品卖点拆解；
- 小红书笔记策划；
- 内容复盘。

真实经历：

曾经帮一个本地摄影工作室把“拍得好看”拆成孕妈照、证件照、亲子照三个场景内容线，第一轮测试后评论更具体。

核心观点：

- 内容不是想到什么发什么；
- 对标账号不能直接抄，要拆结构；
- 小红书笔记要同时解决选题、封面、正文和反馈。

内容禁区：

- 不承诺 7 天涨粉；
- 不承诺爆款；
- 不讲虚假成交案例。

内容主线：

1. 经历故事：我怎么帮小团队拆内容方向；
2. 专业判断：什么样的选题不适合新号；
3. 方法拆解：一篇小红书笔记怎么从卖点开始写。

生成任务示例：

- 内容目的：建立信任；
- 内容主线：方法拆解；
- 正文字数档位：长正文 800-1000 字；
- 本次强调：小红书笔记不是只写正文，还要有封面、配图和反馈。

生成图片示例：

- 图片生成方式：生成配图；
- 输出：封面图 + 3 张辅助配图；
- 图片方向：文字封面、卖点拆解流程图、发布反馈示意图。

3 篇笔记标题示例：

1. 选题别从爆款开始；
2. 卖点怎么变成笔记；
3. 新号先别追大爆款。

反馈示例：

- 评论有人问“能不能帮我看账号”；
- 收藏高于点赞；
- 私信里有 1 个潜在咨询。

优化建议示例：

下一轮继续做“卖点到笔记”的拆解，但标题更具体，封面增加对比句，让用户一眼看出适合谁。

## 原型验收标准

生成原型后，至少要检查：

1. 是否能从登录走到项目创建；
2. 项目大类是否初始化后不可更改；
3. 资料库是否能表达长期资产；
4. 内容管理是否有场景卡入口、素材输入和诊断结果；
5. 内容管理是否突出“P0 每次生成 3 篇，后期可扩展 N 篇”；
6. 任务历史是否能承接反复使用；
7. 笔记详情是否包含标题、字数档位、正文、话题、观察点和诊断依据；
8. 笔记详情是否显示标题 20 字、正文 1000 字和可发布质检；
9. 笔记详情是否能选择生成配图或内容变成图片；
10. 内容变成图片是否显示正文精简版和图片页结构；
11. 发布反馈是否支持手动填写高价值评论；
12. 优化建议是否能引导下一轮生成；
13. 品牌和个人 IP 两个样本是否都能跑通；
13. 页面里是否没有销售、涨粉、爆款承诺。
