# AI 创作工具 / 内容增长工作台 - MVP 验证方案

更新日期：2026-07-01

文档版本：MVP v0.5

当前状态：MVP 验证草稿。

说明：这份文档只用于定义“先验证什么、怎么判断是否值得继续”。当前仍不进入正式开发，也不展开完整首批用户招募、交付和复盘执行。

## 结论

MVP v0.5 要验证的不是“AI 能不能写 3 篇笔记”，而是：

**一人公司、品牌主和个人 IP 能否通过一个轻量工作台，完成一次最低成本的小红书内容实验。**

一次内容实验必须包含：

1. 一个明确场景；
2. 一次手动素材输入；
3. 一个诊断判断；
4. 一个可发布内容包；
5. 一个下一步动作；
6. 一个发布后复盘指标。

## 推荐方案

MVP 名称：

**AI 创作工具 / 内容增长工作台**

对外一句话：

帮一人公司、品牌主和个人 IP，把已有资料、草稿、截图和反馈，转成诊断判断、3 篇可发布小红书笔记和下一轮内容实验。

当前双样本用户：

- 品牌 - 宠物用品；
- 个人 IP - 知识分享。

验证场景先聚焦 3 张卡：

- 草稿改写；
- 发布前体检；
- 发布复盘。

说明：

- 可以在产品中保留 10 张场景卡方向；
- 但真实验证时先不要全量铺开；
- 先用 3 张最高频、最低成本、最容易闭环的场景判断用户是否愿意持续使用。

## 关键依据

用户的真实问题通常不是“我不会写”，而是：

- 不知道这个账号现在该先解决什么；
- 不知道自己的草稿能不能发；
- 不知道该参考什么结构；
- 不知道发完后看什么；
- 不知道下一篇该怎么调整。

因此 MVP 不应该只验证生成能力，而应该验证：

**诊断是否有用，生成是否可发，下一步是否可执行，复盘是否愿意回填。**

## MVP 用户

### 样本 A：品牌 - 宠物用品

目标：

- 在小红书建立品牌认知；
- 讲清楚商品卖点和使用场景；
- 用内容验证用户兴趣、收藏、评论、私信和购买意向。

边界：

- 不承诺销售；
- 不承诺转化率；
- 不做店铺运营；
- 不做广告投放。

### 样本 B：个人 IP - 知识分享

目标：

- 明确账号定位；
- 建立持续发布的内容主线；
- 用内容验证关注、评论、私信和互动意向。

边界：

- 不承诺涨粉；
- 不承诺爆款；
- 不承诺平台推荐；
- 不做个人 IP 陪跑课。

## 新的 MVP 用户路径

首次使用：

**登录 -> 创建项目 -> 完善资料库 -> 生成定位与内容主线 -> 进入内容管理 -> 选择场景卡 -> 提供素材 -> 查看诊断 -> 选择字数 -> 生成 3 篇笔记 -> 单篇生成图片 -> 发布 -> 回填反馈。**

日常使用：

**登录 -> 进入内容管理 -> 选择场景卡 -> 提供本次素材 -> 诊断判断 -> 生成 3 篇笔记 -> 选择一篇发布 -> 数据反馈 -> 获得下一轮实验建议。**

核心不变：

- P0 每次固定生成 3 篇笔记；
- 后期再扩展为 N 篇；
- 笔记生成前先选择正文字数档位；
- 图片生成在单篇笔记详情页触发；
- 图片方式只有“生成配图”和“内容变成图片”。

## 场景卡验证设计

### 1. 草稿改写

用户输入：

- 草稿正文；
- 想表达的核心观点；
- 希望用户看完后的动作；
- 可选截图或参考链接。

诊断输出：

- 草稿最大问题；
- 最值得保留的表达；
- 不建议继续强化的方向；
- 适合改成哪种内容主线。

生成输出：

- 3 篇不同角度的小红书笔记；
- 每篇包含标题、正文、推荐话题、评论引导、发布观察点；
- 用户可进入单篇详情生成配图或内容变成图片。

复盘指标：

- 用户是否愿意发布其中 1 篇；
- 发布后重点看评论质量或收藏。

### 2. 发布前体检

用户输入：

- 准备发布的笔记；
- 封面或配图截图；
- 目标用户；
- 本次发布目的。

诊断输出：

- 标题是否清楚；
- 正文是否超过 1000 字；
- 是否有夸大承诺；
- 是否缺少用户行动引导；
- 是否建议改成图片承载型表达。

生成输出：

- 3 个优化版本；
- 可发布质检结果；
- 适合的推荐话题；
- 图片生成建议。

复盘指标：

- 发布后重点看收藏、评论或主页访问中的一个。

### 3. 发布复盘

用户输入：

- 已发布笔记链接或截图；
- 后台数据截图；
- 高价值评论或私信；
- 用户主观判断。

诊断输出：

- 这篇内容的有效信号；
- 这篇内容的无效信号；
- 下一篇应该延续什么；
- 下一篇应该避开什么。

生成输出：

- 下一轮 3 篇笔记；
- 每篇绑定一个复盘依据；
- 每篇给一个发布观察点。

复盘指标：

- 下一篇是否在目标指标上比上一篇更清晰。

## 其他场景卡方向

P0 可作为产品入口展示，但不作为第一轮重点验证：

1. 主页诊断；
2. 找对标账号；
3. 爆文拆解；
4. 关键词洞察；
5. 7 天发布计划；
6. 内容知识库；
7. 变现判断。

这些场景卡暂时只需要在 PRD 和原型里保留入口，不急着做完整能力。

## 暂不做什么

- 不做一键搬运；
- 不做洗稿；
- 不做自动发布；
- 不做自动私信；
- 不做小红书账号授权；
- 不做平台爬取；
- 不做自动解析平台数据；
- 不做大规模对标账号库；
- 不做完整素材库自动采集；
- 不做复杂 A/B 测试；
- 不做完整会员体系；
- 不做独立图片设计器；
- 不承诺品牌项目产生销售；
- 不承诺个人 IP 涨粉；
- 不承诺爆款。

## 最小验证方式

当前不急着扩展功能，也不急着做完整招募。

先准备两套模拟输入和三张场景卡样本：

1. 品牌 - 宠物样本；
2. 个人 IP - 知识分享样本；
3. 草稿改写；
4. 发布前体检；
5. 发布复盘。

每次验证只看：

- 用户是否能顺利提供素材；
- 诊断判断是否让用户觉得“说中了问题”；
- 3 篇笔记里是否至少有 1 篇愿意发布；
- 用户是否知道下一步只做什么；
- 用户是否愿意回填一个复盘指标。

## 风险

### 风险 1：场景卡让 MVP 变复杂

应对方式：

场景卡只是入口，不增加左侧主菜单；第一轮只重点验证 3 张卡。

### 风险 2：诊断结果泛泛而谈

应对方式：

诊断必须给出“问题、机会、不建议做什么、下一步动作”，并且必须连接后续 3 篇笔记。

### 风险 3：手动输入素材让用户嫌麻烦

应对方式：

P0 只要求最小输入：一段草稿、一张截图、一个链接或一个关键词即可启动，不要求一次填完整资料。

### 风险 4：用户仍然只把它当文案生成器

应对方式：

页面和文档中把“诊断判断、下一步动作、复盘指标”放在生成之前和生成之后，不只展示文案。

### 风险 5：图片生成让 MVP 变重

应对方式：

图片仍然只在单篇笔记详情页触发，只保留生成配图和内容变成图片两种方式。
