# 巴布 MVP v0.9 模型与商业化里程碑

- 规划日期：`2026-08-07`
- 产品版本：`MVP v0.9`
- 里程碑版本：`v2026.08.07.3`
- 当前状态：决策与交互原型已收口，真实工程尚未实施
- 详细方案：`../03_产品方案与PRD/17_模型会员积分方案.md`

## 结论

MVP v0.9 确定了巴布上线所需的模型、搜索、质量检查、会员、积分和支付边界，并完成对应交互原型。第一版仍只服务小红书内容创作，核心差异不是提供一个通用写作框，而是持续读取用户的账号定位、商品、个人 IP 优势和历史内容，再生成可直接使用的笔记与配图。

当前原型不表示模型、支付、会员或账务能力已经真实上线。

## 已确认范围

### 模型与生成

- 采用双栈：国内模型为默认链路，海外模型通过中转服务作为用户主动选择的高质量模式；
- 文字和图片分别选择模式，不强制整次任务使用同一档；
- 服务端使用供应商中立的模型网关和别名配置，具体主模型与备用模型通过盲测确定；
- 文字提示词由基础规则、任务模板、账号与商品上下文、历史内容和搜索摘要组成；
- 图片先分析商品与视觉资料，再生成图片提示词；
- 生成完成后执行规则检查与 AI 审核，高质量模式固定进行 AI 审核和一次优化；
- 目标是从发起生成到结果返回控制在 30-60 秒内。

### 数据与搜索

- 每次创作任务先做一次近期信息搜索，同一任务的 1-5 篇笔记共享搜索结果；
- 第一版只使用官方 API 与公开可搜索内容，不抓取小红书、抖音或公众号页面；
- 独立搜索服务负责过滤、摘要、去重和结构化，模型不直接接收大量原始网页；
- 预留付费第三方社媒数据服务，不在第一版实现；
- 第一版只生成小红书笔记，抖音与微信公众号作为后续平台模板扩展。

### 会员与积分

- 只设一套会员权益，月、季、年仅时长和价格不同；
- 月会员 `88 元`，季度会员 `228 元`，年会员 `688 元`；
- 会员可不限数量添加账号、商品与个人 IP 资料；
- 每个会员月开始发放 `1000` 会员赠送积分，该会员月结束时清零；季度和年会员也按会员月分批发放；
- 赠送积分优先消耗，购买积分按最早到期顺序消耗；
- 购买积分有效期 12 个月，会员到期后冻结，续费后恢复；
- 积分包为 `300 / 29 元`、`1000 / 79 元`、`3000 / 199 元`；
- 非会员不能购买或使用积分，不提供免费生成次数。

### 计费

| 能力 | 标准模式 | 高质量模式 |
| --- | ---: | ---: |
| 文字笔记 | 3 积分/篇 | 6 积分/篇 |
| 内容场景图 | 10 积分/张 | 20 积分/张 |
| 商品展示图 | 20 积分/张 | 40 积分/张 |

- 一次文字任务包含一次免费重新生成，之后每次成功重新生成正常计费；
- 图片按成功生成张数计费；
- 系统、搜索或模型失败不扣积分；
- 内测期可调整积分消耗，正式付费上线后只对新会员周期和新购买积分生效。

### 支付与到期

- 中国大陆用户通过微信支付或支付宝扫码付款；
- 支付回调成功后才激活会员或积分包；
- 不自动续费，到期前 7、3、1 天提醒；
- 会员到期后停止生成，历史内容仍可查看和下载；
- 退款、重复回调、支付超时和到账延迟必须进入账务异常处理。

## 内容历史选择

用户可见历史采用方案 A：只保存标题、正文、话题和生成图片，按账号组织并直接供用户复制或下载。

模型、搜索、提示词版本、质检分数、积分流水和成本作为内部运行记录单独保存，用于排错、对账和评测，不在创作历史中展示，也不将其包装成用户内容资产。普通运行日志不保存完整账号/商品快照、完整 Prompt 或原始网页，并设置有限保留周期；后续 RAG 只在用户授权且数据边界明确后启用。

## 成本红线

- 年会员月均收入约 `57.3 元`；
- 目标综合毛利率不低于 `65%`；
- 年会员月均直接成本目标不超过 `20 元`；
- 建议月均成本上限：图片 `12 元`、文字 `2 元`、搜索 `3 元`、存储支付与其他 `3 元`；
- 若成本超线，优先调整高成本能力的积分消耗或减少赠送量，不降低已确认的内容质量标准，也不临时改变已售周期权益。

## 上线前门槛

1. 使用 3-5 名真实试用者和 30-50 个盲测任务选择文字主模型与备用模型；
2. 至少 80% 的输出被用户判断为可直接使用或只需极少修改；
3. 商品图主体、颜色和关键结构通过人工核验，不以通用场景图冒充真实商品图；
4. 积分冻结、恢复、扣减、退款与失败返还均可追溯且幂等；
5. 微信和支付宝扫码支付分别完成成功、取消、超时、重复回调和延迟到账测试；
6. 高风险行业在第一版被拒绝或引导至安全范围。

## 第一版不做

- 不拆成个人版、团队版或多套会员；
- 不处理共享账号和复杂设备风控；
- 不做自动续费；
- 不做小红书绑定、Cookie 托管或自动发布；
- 不做抖音、微信公众号内容生成；
- 不做平台页面抓取和浏览器模拟采集；
- 不做模型微调、知识图谱或自动多模型竞价路由；
- 不开放医疗诊断、处方、药品功效，保健品治疗承诺，证券、投资、加密资产收益承诺及法律结论类生成。
