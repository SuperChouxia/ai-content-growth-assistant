- 不做一键搬运；
- 不做洗稿；
- 不做自动发布；
- 不做自动私信；
- 不承诺爆款；
- 暂不展开首批用户如何招募、筛选、交付和复盘；
- 暂不做产品设计、低保真线框、高保真视觉；
- 产品方案完全确定前，暂不开发代码、技术架构或自动化生成能力。

当前阶段停在 PRD，不继续进入产品设计层。

1. 是否要把 PRD 转成可视化低保真线框；
2. 是否要先做人工增强验证；
3. 是否进入开发。
