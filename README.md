# 小红书定位与内容验证助手

这是一个面向品牌和个人 IP 的小红书定位与内容验证项目。P0 先以品牌-宠物和个人 IP-知识分享作为样本。

当前阶段只沉淀市场、运营、产品需求和原型文档。暂时不推进开发实现。

## 当前主线

MVP v0.4 已收敛为：

**登录 -> 项目管理 -> 资料库 -> 选择字数生成 3 篇笔记 -> 单篇笔记生成配图或内容变成图片 -> 数据反馈 -> 下一轮优化。**

## 协作约定

- 文档产出先保存到本地；
- 用户确认后再同步 GitHub。

## 暂停项

- 不做一键搬运；
- 不做洗稿；
- 不做自动发布；
- 不做自动私信；
- 不做开放式文生图；
- 不做复杂图片编辑器；
- 不自动生成真实商品图；
- 不承诺爆款；
- 品牌项目不承诺销售；
- 个人 IP 不承诺涨粉；
- 暂不展开首批用户招募、筛选、交付和复盘；
- 暂不做高保真视觉；
- 产品方案完全确定前，暂不开发代码或技术架构。
