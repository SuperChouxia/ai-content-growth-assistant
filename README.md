# AI 创作工具 / 内容增长工作台

当前版本：MVP v0.5

这是一个面向一人公司、品牌主和个人 IP 的小红书内容增长工作台。P0 先以品牌-宠物和个人 IP-知识分享作为验证样本。

当前阶段只沉淀市场、运营、产品需求和原型文档。暂时不推进开发实现。

## 当前主线

MVP v0.5 在 v0.4 “先正文后图片”闭环上，新增“场景卡入口”和“先诊断再生成”的产品层。

核心路径：

**登录 -> 项目管理 -> 资料库 -> 内容管理选择场景卡 -> 手动提供素材 -> 先输出诊断判断 -> 选择字数生成 3 篇笔记 -> 单篇笔记生成配图或内容变成图片 -> 数据反馈 -> 下一轮优化。**

仍然保留的硬边界：

- 左侧主菜单只保留：项目管理、内容管理、数据反馈；
- 资料库仍在项目管理内部，是长期资料中枢；
- P0 每次固定生成 3 篇笔记，后期再扩展为 N 篇；
- 图片能力是单篇笔记详情里的二段动作，不是独立设计器；
- P0 不做平台爬取、自动解析、大规模账号库或自动发布。

## 协作约定

- 文档产出先保存到本地；
- 用户确认后再同步 GitHub。

## 版本记录

### MVP v0.5

- 产品定位升级为“面向一人公司 / 自媒体获客者的内容增长工作台”；
- 内容管理前置增加场景卡入口；
- 场景卡先诊断，再生成可发布内容；
- MVP 素材入口改为用户手动输入链接、截图、草稿、关键词、后台数据截图；
- 每次输出只围绕一个可发布内容包、一个下一步动作、一个复盘指标。

### MVP v0.4

- 固化“先选择字数 -> 生成 3 篇笔记 -> 单篇详情生成配图或内容变成图片”；
- 把生图能力纳入发布闭环，但不做独立图片设计器。

- 不做一键搬运；
- 不做洗稿；

- 不做自动私信；

- 不做自动解析小红书、抖音、公众号数据；

- 不做复杂图片编辑器；
