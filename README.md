# AI 创作工具 / 内容增长工作台

当前版本：MVP v0.8（里程碑 `v2026.08.07.2`）

这是一个面向一人公司、品牌主和个人 IP 的小红书内容增长工作台。P0 先以品牌-宠物和个人 IP-知识分享作为验证样本。

当前阶段已完成市场、运营、产品需求、产品设计、技术方案和可交互静态原型的里程碑收口。原型用于验证信息架构与交互，不代表已接入真实 AI、账号解析、图片生成或持久化后端。

## 当前主线

MVP v0.8 以登录后三列工作台为核心：左侧是“对话、创作、账号”一级菜单，中栏随当前模块承载对话列表或账号列表，右侧是当前任务工作区。对话已开放为独立的 GPT 式助手窗口；创作按“内容/商品主线 -> 生成设置 -> 笔记预览 -> 笔记详情 -> 生成配图”完成闭环；账号页保留多账号、品牌/个人 IP 和商品资料；左侧底部的个人中心使用整块右侧区域承载注册信息、修改密码和退出登录。

核心路径：

**首页 -> 登录 -> 账号创建/选择 -> 在对话中梳理选题和表达，或进入创作选择内容/商品主线 -> 设置字数和 1-5 篇数量 -> 生成笔记预览 -> 查看只读笔记详情 -> 选择 1-6 张生成配图 -> 在创作历史中按账号回看；用户也可进入个人中心查看登录账号、修改密码或退出。**

仍然保留的硬边界：

- 产品框架分为登录、对话、创作、账号；
- 首页只承担产品介绍和登录入口，登录成功后进入账号卡片式工作台；
- 登录后固定使用左侧一级菜单，对话、创作、账号分别使用三列布局；
- 登录只做账号密码登录，不做注册、验证码、微信登录或小红书授权；
- 账号管理就是原项目管理，资料库仍在账号管理内部，是长期资料中枢；
- P0 内容主线生成支持 1-5 篇笔记，最多 5 篇；
- P0 对话用于自由梳理选题、定位、草稿和改写需求，支持新建、搜索、历史切换和消息发送；
- 对话标题居中、历史项等高，输入聚焦不出现额外边框；
- 笔记生成后直接作为可用结果展示，当前里程碑不提供编辑、状态或保存按钮；
- 图片能力是单篇笔记详情里的二段动作，支持一次生成 1-6 张配图，不是独立设计器；
- 个人中心包含注册信息、原型级修改密码和退出确认，充值与消费记录仅保留禁用入口；
- P0 以手动录入账号资料为可靠路径，不做后台授权、持续监控、大规模账号库、自动解析发布数据或自动发布。
