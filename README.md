# 小红书定位与内容验证助手

这是一个面向品牌和个人 IP 的小红书定位与内容验证项目。P0 先以品牌-宠物和个人 IP-知识分享作为样本。

当前阶段只沉淀市场、运营和产品需求文档。暂时不进入产品设计层，也不推进开发实现。

## 当前主线

MVP v0.3 已收敛为：

**登录 -> 项目管理 -> 资料库 -> 内容生产区 P0 每次生成 3 篇图文笔记 -> 数据反馈 -> 下一轮优化。**

## 暂停项

- 不做一键搬运；
- 不做洗稿；
- 不做自动发布；
- 不做自动私信；
- 不承诺爆款；
- 品牌项目不承诺销售；
- 个人 IP 不承诺涨粉；
- 暂不展开首批用户招募、筛选、交付和复盘；
- 暂不做产品设计、低保真线框、高保真视觉；
- 产品方案完全确定前，暂不开发代码、技术架构或自动化生成能力。
