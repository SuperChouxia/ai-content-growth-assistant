# 小红书定位与内容验证助手

这是一个面向宠物品牌和个人 IP 的小红书定位与内容验证项目。

当前阶段只沉淀市场、运营和产品需求文档。暂时不进入产品设计层，也不推进开发实现。

## 当前主线

MVP v0.1 已收敛为：

**资料采集 -> 账号定位 -> 内容主线 -> 选题池 -> 3 篇图文笔记生成 -> 发布反馈 -> 下一轮优化。**

## 暂停项

- 不做一键搬运；
- 不做洗稿；
- 不做自动发布；
- 不做自动私信；
- 不承诺爆款；
- 宠物品牌不承诺销售；
- 个人 IP 不承诺涨粉；
- 暂不展开首批用户招募、筛选、交付和复盘；
- 暂不做产品设计、低保真线框、高保真视觉；
- 产品方案完全确定前，暂不开发代码、技术架构或自动化生成能力。
